# Story 4.3: Timer Controls

**Epic:** 4 - Pomodoro Timer (Focused Execution Tool)
**Story Number:** 4.3
**Status:** Draft

---

## Story

**As a** user,
**I want** to start, pause, stop, and reset the timer,
**so that** I have full control over focus sessions.

---

## Acceptance Criteria

1. Three buttons: restart (circular arrow), play/pause (triangle/pause), stop (square)
2. Styled: chartreuse background, black icons, rounded
3. Play starts countdown, changes to pause icon
4. Pause stops countdown, shows play icon
5. Stop resets to initial time, stops
6. Restart resets to beginning of current mode, starts
7. Buttons disabled at 00:00 when not running
8. Keyboard: Space (play/pause), R (restart), S (stop), Escape (stop)
9. Hover: darker chartreuse
10. Active: scale down slightly
11. Visual feedback on click
12. Zustand actions: startTimer, pauseTimer, stopTimer, restartTimer

### Task 1: Add Control Actions to Pomodoro Store (AC: 12)

- [ ] Update `apps/web/stores/pomodoroStore.ts`:
  ```typescript
  interface PomodoroStore {
    // ... existing state ...

    // AC 12: Control actions
    startTimer: () => void
    pauseTimer: () => void
    stopTimer: () => void
    restartTimer: () => void
  }

  export const usePomodoroStore = create<PomodoroStore>()(
    persist(
      (set, get) => ({
        // ... existing state and actions ...

        // AC 3: Start timer
        startTimer: () => set({ isRunning: true }),

        // AC 4: Pause timer
        pauseTimer: () => set({ isRunning: false }),

        // AC 5: Stop timer (reset to initial)
        stopTimer: () => {
          const { settings } = get()
          set({
            isRunning: false,
            mode: 'focus',
            currentCycle: 1,
            timeRemaining: settings.focusDuration * 60,
          })
        },

        // AC 6: Restart current mode
        restartTimer: () => {
          const { mode, settings } = get()
          const duration = mode === 'focus'
            ? settings.focusDuration * 60
            : settings.breakDuration * 60

          set({
            timeRemaining: duration,
            isRunning: true, // AC 6: Starts after restart
          })
        },
      }),
      { name: 'pomodoro-storage' }
    )
  )
  ```

- [ ] AC 3: Start sets isRunning true
- [ ] AC 4: Pause sets isRunning false

### Task 3: Add Keyboard Shortcuts (AC: 8)

- [ ] Create `apps/web/hooks/usePomodoroKeyboard.ts`:
  ```typescript
  import { useEffect } from 'react'
  import { usePomodoroStore } from '@/stores/pomodoroStore'

  export function usePomodoroKeyboard() {
    const {
      isRunning,
      timeRemaining,
      startTimer,
      pauseTimer,
      stopTimer,
      restartTimer,
    } = usePomodoroStore()

    useEffect(() => {
      const handleKeyDown = (event: KeyboardEvent) => {
        // Ignore if typing in input
        if (event.target instanceof HTMLInputElement) return

        const isDisabled = timeRemaining === 0 && !isRunning

        switch (event.key) {
          case ' ': // AC 8: Space for play/pause
            event.preventDefault()
            if (!isDisabled) {
              isRunning ? pauseTimer() : startTimer()
            }
            break

          case 'r':
          case 'R': // AC 8: R for restart
            event.preventDefault()
            if (!isDisabled) {
              restartTimer()
            }
            break

          case 's':
          case 'S': // AC 8: S for stop
            event.preventDefault()
            if (!isDisabled) {
              stopTimer()
            }
            break

          case 'Escape': // AC 8: Escape for stop
            event.preventDefault()
            if (!isDisabled) {
              stopTimer()
            }
            break
        }
      }

      window.addEventListener('keydown', handleKeyDown)
      return () => window.removeEventListener('keydown', handleKeyDown)
    }, [isRunning, timeRemaining, startTimer, pauseTimer, stopTimer, restartTimer])
  }
  ```
- [ ] AC 8: Space = play/pause
- [ ] AC 8: R = restart
- [ ] AC 8: S or Escape = stop
- [ ] Prevent default to avoid page scroll
- [ ] Ignore if typing in input

### Task 4: Integrate Controls into PomodoroTimer

- [ ] Update `apps/web/components/pomodoro/PomodoroTimer.tsx`:
  ```typescript
  'use client'

  import { useEffect } from 'react'
  import { usePomodoroStore } from '@/stores/pomodoroStore'
  import { usePomodoroKeyboard } from '@/hooks/usePomodoroKeyboard'
  import { CircularTimer } from './CircularTimer'
  import { TimerControls } from './TimerControls'

  export function PomodoroTimer() {
    const { timeRemaining, isRunning, mode, currentCycle, settings, tick } =
      usePomodoroStore()

    // AC 8: Keyboard shortcuts
    usePomodoroKeyboard()

    // Countdown logic (from Story 4.2)
    useEffect(() => {
      if (!isRunning) return
      const interval = setInterval(() => tick(), 1000)
      return () => clearInterval(interval)
    }, [isRunning, tick])

    const formatTime = (seconds: number): string => {
      const mins = Math.floor(seconds / 60)
      const secs = seconds % 60
      return `${mins.toString().padStart(2, '0')}:${secs.toString().padStart(2, '0')}`
    }

    const totalDuration =
      mode === 'focus' ? settings.focusDuration * 60 : settings.breakDuration * 60
    const progressPercentage = (timeRemaining / totalDuration) * 100

    return (
      <div className="flex flex-col items-center justify-center space-y-8">
        <CircularTimer
          timeRemaining={timeRemaining}
          totalDuration={totalDuration}
          progressPercentage={progressPercentage}
          formattedTime={formatTime(timeRemaining)}
          mode={mode}
        />

        <div className="text-sm text-gray-600">
          Cycle {currentCycle} / {settings.repetitions}
        </div>

        {/* Timer controls */}
        <TimerControls />

        {/* Keyboard hints */}
        <div className="text-xs text-gray-500 text-center">
          <p>Espace: Démarrer/Pause • R: Redémarrer • S/Échap: Arrêter</p>
        </div>
      </div>
    )
  }
  ```

## Dev Notes

### Button Styling (AC 2, 9, 10, 11)

**Chartreuse (#D9FC00):**
Brand color, high visibility.

**Black icons (#262626):**
Max contrast on chartreuse.

**Rounded:**
```css
rounded-full
```
Circular buttons (h-14 w-14, h-16 w-16).

**Hover (#c4e600):**
Slightly darker chartreuse.

**Active scale:**
```css
active:scale-95
```
Button "presses" down.

**Transition:**
```css
transition-all duration-150
```
Smooth hover/active feedback.

### Play/Pause Toggle (AC 3, 4)

**Single button:**
```typescript
{isRunning ? <Pause /> : <Play />}
```

**Why?**
- Standard pattern (YouTube, Spotify)
- Saves space
- Clear state indication

### Stop vs Pause (AC 4, 5)

**Pause:**
- Stops countdown
- Preserves time
- Preserves mode/cycle

**Stop:**
- Stops countdown
- Resets to 25:00
- Resets mode/cycle to initial

**Different actions.**

### Restart Logic (AC 6)

**Resets current mode:**
```
Focus 15:30 → Restart → Focus 25:00 (starts)
Break 02:00 → Restart → Break 05:00 (starts)
```

**Useful when:**
User wants to redo current session.

### Disabled State (AC 7)

**When:**
```typescript
timeRemaining === 0 && !isRunning
```

**Why?**
Timer complete, no action until user resets.

**Styling:**
```css
opacity-50 cursor-not-allowed
```

### Keyboard Shortcuts (AC 8)

**Mnemonics:**
- Space: Standard play/pause
- R: **R**estart
- S: **S**top
- Escape: Universal cancel

**Accessibility:**
Keyboard-only users can control timer.

**Ignore in inputs:**
```typescript
if (event.target instanceof HTMLInputElement) return
```

Prevents conflict when typing.

### Button Sizes

**Play/Pause: 16×16 (larger):**
Most important action.

**Restart/Stop: 14×14 (smaller):**
Secondary actions.

**Visual hierarchy:**
Play/pause stands out.

### Fill vs Stroke Icons

**Filled icons:**
```tsx
<Play fill="#262626" />
```

**Why?**
More visible on chartreuse background.

**Stroke icons:**
Would be too thin.

### Keyboard Hints

**Display shortcuts:**
```
Espace: Démarrer/Pause • R: Redémarrer • S/Échap: Arrêter
```

**Helps users:**
Discover keyboard controls.

**Small, unobtrusive:**
```css
text-xs text-gray-500
```

### Testing Timer Behavior

**Challenge:**
Can't wait 25 minutes in tests.

**Solution:**
Test individual actions (start, pause, stop).

**Mock time:**
Future enhancement for full cycle tests.

### Prevent Default on Space

**Issue:**
Space scrolls page.

**Fix:**
```typescript
event.preventDefault()
```

**Prevents:**
Unwanted page scroll when playing timer.

### Button Accessibility

**ARIA labels:**
```tsx
aria-label="Démarrer"
aria-label="Pause"
```

**Screen reader:**
Announces button purpose.

**Dynamic labels:**
Change based on state.
