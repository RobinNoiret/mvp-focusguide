# Story 4.1: Pomodoro Page UI with Timer Display

**Epic:** 4 - Pomodoro Timer (Focused Execution Tool)
**Story Number:** 4.1
**Status:** Ready for Review

---

## Story

**As a** user,
**I want** a Pomodoro page with a large countdown timer,
**so that** I can track my focus session time at a glance.

---

## Acceptance Criteria

1. Pomodoro page route (/pomodoro) with protected route
2. Layout matches mockup: centered circular timer
3. Circular timer SVG with chartreuse progress ring (depletes clockwise)
4. Timer displays MM:SS (e.g., "26:54") in large bold font
5. Current mode below: "Focus" or "Break"
6. Progress ring animates 360° to 0° as time counts down
7. Centered vertically and horizontally
8. Background: #EDEAE9, text: #262626
9. Sidebar "Pomodoro" active
10. Loading: skeleton timer
11. Timer uses React state for countdown
12. Responsive: timer scales proportionally

  'use client'

  import { useState, useEffect } from 'react'
  import { CircularTimer } from './CircularTimer'

  export function PomodoroTimer() {
    // AC 11: React state for countdown
    const [timeRemaining, setTimeRemaining] = useState(25 * 60) // 25 minutes in seconds
    const [isRunning, setIsRunning] = useState(false)
    const [mode, setMode] = useState<'focus' | 'break'>('focus')

          mode={mode} // AC 5: Focus or Break
        />

        {/* Timer controls will be added in Story 4.3 */}
      </div>
    )
  }

### Task 4: Create CircularTimer Component (AC: 3, 4, 5, 6, 8, 12)

- [x] Create `apps/web/components/pomodoro/CircularTimer.tsx`:
  ```typescript
  'use client'

  interface CircularTimerProps {
    timeRemaining: number
    totalDuration: number
    progressPercentage: number
    formattedTime: string
    mode: 'focus' | 'break'
  }

  export function CircularTimer({
    timeRemaining,
    totalDuration,
    progressPercentage,
    formattedTime,
    mode,
  }: CircularTimerProps) {
    // AC 3, 6: SVG circle parameters
    const size = 320 // AC 12: Responsive size
    const strokeWidth = 8
    const radius = (size - strokeWidth) / 2
    const circumference = 2 * Math.PI * radius

    // AC 6: Offset for progress ring (depletes clockwise)
    const offset = circumference - (progressPercentage / 100) * circumference

    return (
      <div className="relative" style={{ width: size, height: size }}>
        {/* AC 3: SVG circular timer */}
        <svg width={size} height={size} className="transform -rotate-90">
          {/* Background circle */}
          <circle
            cx={size / 2}
            cy={size / 2}
            r={radius}
            fill="none"
            stroke="#e5e7eb"
            strokeWidth={strokeWidth}
          />

          {/* AC 3: Chartreuse progress ring */}
          <circle
            cx={size / 2}
            cy={size / 2}
            r={radius}
            fill="none"
            stroke="#D9FC00"
            strokeWidth={strokeWidth}
            strokeDasharray={circumference}
            strokeDashoffset={offset}
            strokeLinecap="round"
            className="transition-all duration-1000 ease-linear"
          />
        </svg>

        {/* AC 4, 5, 8: Time and mode display */}
        <div className="absolute inset-0 flex flex-col items-center justify-center">
          {/* AC 4: MM:SS in large bold font */}
          <div className="text-6xl font-bold text-[#262626] tabular-nums">
            {formattedTime}
          </div>

          {/* AC 5: Current mode below */}
          <div className="mt-4 text-lg font-medium text-gray-600">
            {mode === 'focus' ? 'Focus' : 'Pause'}
          </div>
        </div>
      </div>
    )
  }
  ```

### Task 6: Make Timer Responsive (AC: 12)

- [x] Update CircularTimer for responsive sizing:
  ```typescript
  export function CircularTimer({ ... }: CircularTimerProps) {
    // AC 12: Responsive size based on screen
    const getResponsiveSize = () => {
      if (typeof window === 'undefined') return 320
      if (window.innerWidth < 640) return 240 // Mobile
      if (window.innerWidth < 1024) return 280 // Tablet
      return 320 // Desktop
    }

    const [size, setSize] = useState(getResponsiveSize())

    useEffect(() => {
      const handleResize = () => setSize(getResponsiveSize())
      window.addEventListener('resize', handleResize)
      return () => window.removeEventListener('resize', handleResize)
    }, [])

    // ... rest of component
  }
  ```

## Dev Notes

### Circular Timer SVG Implementation (AC 3, 6)

**SVG Circle Math:**
```typescript
radius = (size - strokeWidth) / 2
circumference = 2 * π * radius
```

**Progress Ring:**
```
strokeDasharray = circumference (full circle)
strokeDashoffset = circumference - (progress% * circumference)
```

**Example:**
- Total: 1500s (25 min)
- Remaining: 750s (12.5 min)
- Progress: 50%
- Offset: circumference * 0.5

**Clockwise depletion:**
`transform: rotate(-90deg)` starts at top, depletes clockwise.

### MM:SS Formatting (AC 4)

**Padding with zeros:**
```typescript
const mins = Math.floor(seconds / 60)
const secs = seconds % 60
return `${mins.toString().padStart(2, '0')}:${secs.toString().padStart(2, '0')}`
```

**Examples:**
- 1554s → "25:54"
- 65s → "01:05"
- 5s → "00:05"

**Tabular nums:**
```css
font-variant-numeric: tabular-nums;
```

Prevents width changes as digits change (0-9 same width).

### Mode Display (AC 5)

**French labels:**
- Focus → "Focus"
- Break → "Pause"

**Position:**
Below timer, centered.

**Styling:**
```css
text-lg font-medium text-gray-600
```

Visible but not competing with time.

### Progress Ring Animation (AC 6)

**Smooth transition:**
```css
transition: stroke-dashoffset 1s linear;
```

**Matches countdown tick:**
Timer updates every 1 second, transition also 1 second.

**Result:**
Smooth, continuous depletion.

### Centered Layout (AC 2, 7)

**Flexbox centering:**
```css
display: flex;
align-items: center;
justify-content: center;
```

**Vertical and horizontal:**
Timer perfectly centered on page.

### Background Color (AC 8)

**#EDEAE9 (Warm beige):**
Matches design system.

**Why?**
- Softer than white
- Easier on eyes during long focus sessions
- Consistent with brand

### Responsive Sizing (AC 12)

**Breakpoints:**
- Mobile (<640px): 240px
- Tablet (640-1024px): 280px
- Desktop (≥1024px): 320px

**Text scales:**
```typescript
const fontSize = size / 5 // Proportional
```

**Result:**
Timer readable on all devices.

### Loading Skeleton (AC 10)

**Why needed?**
- Initial page load
- Fetching Pomodoro settings (Story 4.4)

**Design:**
Matches final timer size and position.

**Duration:**
Typically < 200ms (fast).

### Active Sidebar State (AC 9)

**Chartreuse background:**
```css
bg-[#D9FC00] text-[#262626]
```

**Indicates:**
User is on Pomodoro page.

**Matches:**
Other sidebar active states.

### Timer Icon

**Lucide Timer icon:**
```tsx
<Timer className="h-5 w-5" />
```

**Represents:**
Pomodoro/time tracking.

### Performance: requestAnimationFrame

**Future enhancement:**
```typescript
useEffect(() => {
  let animationFrameId

  const animate = () => {
    setTimeRemaining(prev => prev - (1 / 60))
    animationFrameId = requestAnimationFrame(animate)
  }

  if (isRunning) {
    animationFrameId = requestAnimationFrame(animate)
  }

  return () => cancelAnimationFrame(animationFrameId)
}, [isRunning])
```

**For MVP:**
setInterval(1000ms) is sufficient.

### Accessibility

**ARIA attributes:**
```tsx
<div role="timer" aria-live="polite" aria-atomic="true">
  {formattedTime}
</div>
```

**Screen reader:**
Announces time changes.

**Polite:**
Doesn't interrupt other announcements.

### Z-index Layering

**Timer on top:**
No overlapping elements on Pomodoro page.

**Simplest layer:**
z-0 (default).

### Color Contrast (AC 8)

**WCAG AA compliance:**
- Text: #262626 on #EDEAE9
- Contrast ratio: 13.5:1 (exceeds 4.5:1 requirement)

**Chartreuse ring:**
- #D9FC00 on #EDEAE9
- High visibility

### Font: Tabular Nums

**Why important?**
```
25:54 (width)
00:01 (same width)
```

**Without tabular:**
Width changes → timer jumps.

**With tabular:**
Width constant → smooth appearance.

### Transition Timing

**1-second linear:**
```css
transition: stroke-dashoffset 1s linear;
```

**Why linear?**
Constant speed matches countdown.

**Alternative (ease-out):**
Would feel unnatural.
