# Story 2.4: Project Creation & Editing

**Epic:** 2 - Projects Management (Strategic Planning Layer)
**Story Number:** 2.4
**Status:** Draft

---

## Story

**As a** user,
**I want** to create and edit projects,
**so that** I can organize my work.

---

## Acceptance Criteria

1. "Gérer les projets" opens create modal
2. Modal fields: title, description, deadline, tags (comma-separated)
3. React Hook Form validation
4. Save calls POST /v1/projects, adds to grid optimistically
5. Three-dot menu has "Modifier" option
6. Edit modal pre-fills data
7. Save calls PATCH, updates optimistically
8. Tags as colored pills
9. Date picker styled with chartreuse
10. Optimistic updates with rollback on failure
11. Keyboard: Enter to save, Escape to cancel
12. Unit tests for form validation

### Task 3: Create TagInput Component (AC: 8)

- [ ] Create `apps/web/components/ui/tag-input.tsx`:
  ```typescript
  'use client'

  import { useState, KeyboardEvent } from 'react'
  import { X } from 'lucide-react'
  import { Input } from '@/components/ui/input'

  interface TagInputProps {
    tags: string[]
    onTagsChange: (tags: string[]) => void
    placeholder?: string
    maxTags?: number
  }

  export function TagInput({
    tags,
    onTagsChange,
    placeholder = 'Ajouter un tag',
    maxTags = 10,
  }: TagInputProps) {
    const [inputValue, setInputValue] = useState('')

    const addTag = (tag: string) => {
      const trimmedTag = tag.trim()
      if (!trimmedTag) return
      if (tags.includes(trimmedTag)) return
      if (tags.length >= maxTags) return

      onTagsChange([...tags, trimmedTag])
      setInputValue('')
    }

    const removeTag = (indexToRemove: number) => {
      onTagsChange(tags.filter((_, index) => index !== indexToRemove))
    }

    const handleKeyDown = (e: KeyboardEvent<HTMLInputElement>) => {
      if (e.key === 'Enter') {
        e.preventDefault()
        addTag(inputValue)
      } else if (e.key === ',' || e.key === 'Tab') {
        e.preventDefault()
        addTag(inputValue)
      } else if (e.key === 'Backspace' && !inputValue && tags.length > 0) {
        removeTag(tags.length - 1)
      }
    }

    const handleBlur = () => {
      if (inputValue.trim()) {
        addTag(inputValue)
      }
    }

    // Parse comma-separated tags on paste
    const handlePaste = (e: React.ClipboardEvent) => {
      e.preventDefault()
      const pastedText = e.clipboardData.getData('text')
      const newTags = pastedText
        .split(',')
        .map((tag) => tag.trim())
        .filter((tag) => tag && !tags.includes(tag))
        .slice(0, maxTags - tags.length)

      if (newTags.length > 0) {
        onTagsChange([...tags, ...newTags])
      }
    }

    // Tag colors (AC 8)
    const tagColors = [
      'bg-blue-100 text-blue-700',
      'bg-green-100 text-green-700',
      'bg-yellow-100 text-yellow-700',
      'bg-purple-100 text-purple-700',
      'bg-pink-100 text-pink-700',
      'bg-indigo-100 text-indigo-700',
      'bg-red-100 text-red-700',
      'bg-cyan-100 text-cyan-700',
    ]

    const getTagColor = (index: number) => {
      return tagColors[index % tagColors.length]
    }

    return (
      <div className="space-y-2">
        {/* Tags display (AC 8) */}
        {tags.length > 0 && (
          <div className="flex flex-wrap gap-2">
            {tags.map((tag, index) => (
              <span
                key={index}
                className={`inline-flex items-center gap-1 rounded-full px-3 py-1 text-sm font-medium ${getTagColor(
                  index
                )}`}
              >
                {tag}
                <button
                  type="button"
                  onClick={() => removeTag(index)}
                  className="ml-1 rounded-full hover:bg-black/10"
                  aria-label={`Supprimer ${tag}`}
                >
                  <X className="h-3 w-3" />
                </button>
              </span>
            ))}
          </div>
        )}

        {/* Input field */}
        <Input
          value={inputValue}
          onChange={(e) => setInputValue(e.target.value)}
          onKeyDown={handleKeyDown}
          onBlur={handleBlur}
          onPaste={handlePaste}
          placeholder={
            tags.length >= maxTags
              ? `Maximum ${maxTags} tags atteint`
              : placeholder
          }
          disabled={tags.length >= maxTags}
        />
      </div>
    )
  }
  ```

### Task 5: Create useCreateProject Hook (AC: 4, 10)

  ```typescript
  import { useMutation, useQueryClient } from '@tanstack/react-query'
  import { projectService } from '@/services/projectService'
  import type { CreateProjectInput, ProjectWithStats } from '@focus-guide/shared'
  import { toast } from '@/hooks/use-toast'

  export function useCreateProject() {
    const queryClient = useQueryClient()

    return useMutation({
      mutationFn: (input: CreateProjectInput) =>
        projectService.createProject(input),

      // AC 4, 10: Optimistic update
      onMutate: async (newProject) => {
        // Cancel outgoing queries
        await queryClient.cancelQueries({ queryKey: ['projects'] })

        // Snapshot previous value
        const previousProjects = queryClient.getQueryData<ProjectWithStats[]>([
          'projects',
        ])

        // Optimistically update cache
        queryClient.setQueryData<ProjectWithStats[]>(['projects'], (old) => {
          const optimisticProject: ProjectWithStats = {
            id: `temp-${Date.now()}`,
            user_id: 'current-user', // Will be replaced by server
            title: newProject.title,
            description: newProject.description || null,
            deadline: newProject.deadline || null,
            tags: newProject.tags || [],
            created_at: new Date().toISOString(),
            updated_at: new Date().toISOString(),
            deleted_at: null,
            task_count: 0,
            completion_percentage: 0,
            task_counts: {
              backlog: 0,
              todo: 0,
              in_progress: 0,
              done: 0,
            },
          }

          return old ? [...old, optimisticProject] : [optimisticProject]
        })

        return { previousProjects }
      },

      // AC 10: Rollback on error
      onError: (err, newProject, context) => {
        // Rollback to previous state
        queryClient.setQueryData(['projects'], context?.previousProjects)

        toast({
          title: 'Erreur',
          description: 'Impossible de créer le projet. Veuillez réessayer.',
          variant: 'destructive',
        })
      },

      // Refetch to get server data
      onSuccess: () => {
        queryClient.invalidateQueries({ queryKey: ['projects'] })

        toast({
          title: 'Succès',
          description: 'Projet créé avec succès',
        })
      },
    })
  }
  ```
- [ ] Optimistic update: Project appears immediately in grid (AC 4)
- [ ] Rollback on API failure (AC 10)
- [ ] Toast notifications for success/error

### Task 6: Create useUpdateProject Hook (AC: 7, 10)

- [ ] Create `apps/web/hooks/useUpdateProject.ts`:
  ```typescript
  import { useMutation, useQueryClient } from '@tanstack/react-query'
  import { projectService } from '@/services/projectService'
  import type { UpdateProjectInput, ProjectWithStats } from '@focus-guide/shared'
  import { toast } from '@/hooks/use-toast'

  export function useUpdateProject() {
    const queryClient = useQueryClient()

    return useMutation({
      mutationFn: ({ id, data }: { id: string; data: UpdateProjectInput }) =>
        projectService.updateProject(id, data),

      // AC 7, 10: Optimistic update
      onMutate: async ({ id, data }) => {
        await queryClient.cancelQueries({ queryKey: ['projects'] })

        const previousProjects = queryClient.getQueryData<ProjectWithStats[]>([
          'projects',
        ])

        // Optimistically update
        queryClient.setQueryData<ProjectWithStats[]>(['projects'], (old) => {
          return old?.map((project) =>
            project.id === id
              ? {
                  ...project,
                  title: data.title ?? project.title,
                  description: data.description ?? project.description,
                  deadline: data.deadline ?? project.deadline,
                  tags: data.tags ?? project.tags,
                  updated_at: new Date().toISOString(),
                }
              : project
          )
        })

        // Also update single project cache if exists
        queryClient.setQueryData(['projects', id], (old: ProjectWithStats) => {
          if (!old) return old
          return {
            ...old,
            title: data.title ?? old.title,
            description: data.description ?? old.description,
            deadline: data.deadline ?? old.deadline,
            tags: data.tags ?? old.tags,
            updated_at: new Date().toISOString(),
          }
        })

        return { previousProjects }
      },

      // AC 10: Rollback on error
      onError: (err, variables, context) => {
        queryClient.setQueryData(['projects'], context?.previousProjects)

        toast({
          title: 'Erreur',
          description: 'Impossible de modifier le projet. Veuillez réessayer.',
          variant: 'destructive',
        })
      },

      onSuccess: (_, { id }) => {
        queryClient.invalidateQueries({ queryKey: ['projects'] })
        queryClient.invalidateQueries({ queryKey: ['projects', id] })

        toast({
          title: 'Succès',
          description: 'Projet modifié avec succès',
        })
      },
    })
  }
  ```
- [ ] Optimistic update: Changes appear immediately (AC 7)
- [ ] Update both list cache and single project cache
- [ ] Rollback on failure (AC 10)

  ```typescript
  export interface Toast {
    id: string
    title: string
    description?: string
    variant?: 'default' | 'destructive'

  export function useToast() {
    const [toasts, setToasts] = useState<Toast[]>([])

    const toast = ({
      title,
      description,
      variant = 'default',
    }: Omit<Toast, 'id'>) => {
      const id = Math.random().toString(36).substr(2, 9)
      const newToast: Toast = { id, title, description, variant }

      setToasts((prev) => [...prev, newToast])

      // Auto-dismiss after 3 seconds
      setTimeout(() => {
        setToasts((prev) => prev.filter((t) => t.id !== id))
      }, 3000)

      return id
    }

    const dismiss = (id: string) => {
      setToasts((prev) => prev.filter((t) => t.id !== id))
    }

    return { toast, toasts, dismiss }
  }
  ```

### Form Validation Strategy

**React Hook Form + Zod Schema:**

React Hook Form provides:
- ✅ Performance (uncontrolled components, minimal re-renders)
- ✅ Developer experience (simple API)
- ✅ Built-in validation
- ✅ Error handling

- ✅ Type-safe schemas

- ✅ Composable schemas

**Validation schema:**
```typescript
const createProjectSchema = z.object({

  description: z.string().max(2000).optional(),
  deadline: z.date().nullable().optional(),
  tags: z.array(z.string()).max(10).optional(),
})
```

**Benefits:**
- Compile-time type safety
- Runtime validation (prevents invalid API calls)
- Consistent with backend validation (Story 2.2)
- Error messages customizable

**Alternative: Manual validation**
```typescript
if (!title) setError('Title required')
```

Cons: Verbose, error-prone, no type safety.

### Optimistic UI Pattern

**Optimistic update flow:**
1. User clicks "Créer"
2. Project appears in grid immediately (temp ID)
3. API call sent in background
4. On success: Replace temp ID with server ID
5. On error: Remove temp project, show error

**React Query implementation:**
```typescript
onMutate: async (newProject) => {
  // Cancel ongoing queries
  await queryClient.cancelQueries(['projects'])

  // Snapshot current state
  const previous = queryClient.getQueryData(['projects'])

  // Update cache optimistically
  queryClient.setQueryData(['projects'], old => [...old, tempProject])

  return { previous } // For rollback
}

onError: (err, variables, context) => {
  // Rollback on error
  queryClient.setQueryData(['projects'], context.previous)
}
```

**Why optimistic updates?**
- ✅ Instant feedback (feels fast)
- ✅ Builds user trust (app never lags)
- ✅ Handles offline gracefully (queued mutations)

**Trade-off:**
- Complex error handling
- Temporary state can confuse if not handled well
- Requires rollback logic

For task manager: Users expect instant updates, worth the complexity.

### Optimistic Update Cache Strategy

**Two cache keys to update:**
1. `['projects']` - List of all projects (grid view)
2. `['projects', id]` - Single project (detail view, Story 2.5)

**Why both?**
- User edits project from grid → grid updates
- User edits project from detail page → detail updates
- Both views must stay in sync

**Update pattern:**
```typescript

  old.map(p => p.id === id ? { ...p, ...updates } : p)

)
```

```typescript
onSuccess: (_, { id }) => {

}
```

Forces refetch to get server state (completion percentage, updated_at, etc.).

### Three-Dot Menu Integration (AC 5)

```typescript
const handleCardClick = (e: React.MouseEvent) => {
```

### Date Handling Edge Cases

**Timezone issues:**
```typescript
// User selects: 2026-12-25
// Browser sends: 2026-12-25T00:00:00.000Z (UTC)
// Server receives: 2026-12-24 (if server in UTC-1)
```

**Solution:**
Send date-only string (no timezone):
```typescript
date.toISOString().split('T')[0] // "2026-12-25"
```

Backend stores as `DATE` type (no time, no timezone).

**Display:**
```typescript
format(new Date(project.deadline), 'dd/MM/yyyy', { locale: fr })
```
Displays in user's locale.
