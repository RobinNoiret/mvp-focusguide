[Source: docs/prd.md#Visual Design System]

**Primary Font: BN Recon Grotesk**
- Use for: Headings, navigation, UI elements, kanban headers

- Licensing: Ensure proper licensing for web use

**Secondary Font: Inter**
- Use for: Body text, card content, descriptions, labels
- Characteristics: Readable, neutral, variable font support
- Source: Google Fonts (free, open source)

**Font Loading Strategy:**
```typescript
// app/layout.tsx
import { Inter } from 'next/font/google'
import localFont from 'next/font/local'

const inter = Inter({ subsets: ['latin'], variable: '--font-inter' })
const bnRecon = localFont({
  src: './fonts/BNReconGrotesk.woff2',
  variable: '--font-bn-recon',
})

export default function RootLayout({ children }) {
  return (
    <html lang="fr" className={`${inter.variable} ${bnRecon.variable}`}>
      <body className="font-secondary">{children}</body>
    </html>
  )
}
```

### Preventing Layout Shift (CLS) (AC 12)

[Source: docs/prd.md#NFR6 + Performance Targets]

**CLS Target:** < 0.1 (Core Web Vital)

**Strategies:**

1. **Explicit Sizing:**
   - Set height on sidebar: `h-screen` (100vh)
   - Set min-height on kanban columns: `min-h-[400px]`
   - Reserve space for side panel: `w-80` (320px)

2. **Skeleton Loaders:**
   - Show skeleton for sidebar during hydration
   - Show skeleton for kanban columns while loading
   - Skeleton must match final layout dimensions

3. **Font Loading:**
   - Use `font-display: swap` for custom fonts
   - Provide fallback fonts with similar metrics
   - Preload critical fonts: `<link rel="preload" as="font">`

4. **Image Optimization:**
   - Use Next.js `<Image>` with explicit width/height

### State Management with Zustand

[Source: docs/architecture.md#Tech Stack]

**Why Zustand for UI State?**
- Lightweight (1KB)
- Simple API (no boilerplate)
- TypeScript support
- React 18 concurrent mode compatible
- Persist middleware for localStorage

**UI Store Example:**
```typescript
// store/uiStore.ts
import { create } from 'zustand'
import { persist } from 'zustand/middleware'

interface UIState {
  sidebarCollapsed: boolean
  sidePanelOpen: boolean
  toggleSidebar: () => void
  toggleSidePanel: () => void
}

export const useUIStore = create<UIState>()(
  persist(
    (set) => ({
      sidebarCollapsed: false,
      sidePanelOpen: false,
      toggleSidebar: () => set((state) => ({ sidebarCollapsed: !state.sidebarCollapsed })),
      toggleSidePanel: () => set((state) => ({ sidePanelOpen: !state.sidePanelOpen })),
    }),
    { name: 'ui-storage' }
  )
)
```

**Usage in Component:**
```tsx
const { sidebarCollapsed, toggleSidebar } = useUIStore()
```
