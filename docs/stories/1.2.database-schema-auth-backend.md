# Story 1.2: Database Schema & User Authentication Backend

**Epic:** 1 - Foundation & Today Page
**Story Number:** 1.2
**Status:** Draft

---

## Story

**As a** developer,
**I want** a PostgreSQL database schema for users and tasks with authentication endpoints,
**so that** users can register and log in securely via API.

---

## Acceptance Criteria

1. PostgreSQL connection configured in AdonisJS
2. Migration for users table: id (UUID), email (unique), password (hashed), name, email_verified, pomodoro_settings (JSONB), timestamps
3. Migration for tasks table: id (UUID), user_id (FK), project_id (nullable FK), title, notes, project_status (enum nullable), today_status (enum nullable), timestamps, deleted_at
4. User model with password hashing via bcrypt (cost 10+) in beforeSave hook
5. Task model with relationships to User
6. POST /v1/auth/register endpoint (email, password, name validation)
7. POST /v1/auth/login returns JWT access (15min) + refresh tokens (7 days)
8. POST /v1/auth/refresh endpoint
9. POST /v1/auth/logout invalidates refresh token
10. Auth middleware validates JWT and attaches user to context
11. Input validation using VineJS
12. Unit tests for auth endpoints
13. Migrations run successfully and can roll back

  import { BaseModel, column, beforeSave } from '@adonisjs/lucid/orm'
  import Hash from '@adonisjs/core/services/hash'

  export default class User extends BaseModel {
    @column({ isPrimary: true })
    declare id: string

    @column()

    @column({ serializeAs: null })
    declare password: string

    @column()

      if (user.$dirty.password) {
        user.password = await Hash.make(user.password)
      }
    }
  }

### Task 7: Implement POST /v1/auth/register Endpoint (AC: 6)

- [ ] Create `app/controllers/auth_controller.ts`
- [ ] Implement `register` method:
  ```typescript
  import User from '#models/User'
  import { registerValidator } from '#validators/auth_validator'
  import type { HttpContext } from '@adonisjs/core/http'

  export default class AuthController {
    async register({ request, response }: HttpContext) {
      const data = await request.validateUsing(registerValidator)

      // Check if user exists
      const existingUser = await User.findBy('email', data.email)
      if (existingUser) {
        return response.conflict({ error: 'Email already registered' })
      }

      const user = await User.create({
        email: data.email,
        password: data.password, // Auto-hashed by beforeSave hook
        name: data.name,
        emailVerified: false,
        pomodoroSettings: {
          focusDuration: 25,
          breakDuration: 5,
          repetitions: 3,
          autoSwitch: false,
        },
      })

      return response.created({
        id: user.id,
        email: user.email,
        name: user.name,
        emailVerified: user.emailVerified,
      })
    }
  }
  ```
- [ ] Add route in `start/routes.ts`: `router.post('/auth/register', [AuthController, 'register'])`
- [ ] Test with Postman/Thunder Client

- [ ] Implement `login` method in AuthController:
  ```typescript
  async login({ request, response }: HttpContext) {
    const { email, password } = await request.validateUsing(loginValidator)

    const user = await User.findBy('email', email)
    if (!user) {
      return response.unauthorized({ error: 'Invalid credentials' })
    }

    const isValid = await Hash.verify(user.password, password)
    if (!isValid) {
      return response.unauthorized({ error: 'Invalid credentials' })
    }

    const accessToken = await User.accessTokens.create(user, ['*'], {
      expiresIn: '15 minutes',
    })

    const refreshToken = await User.refreshTokens.create(user, ['*'], {
      expiresIn: '7 days',
    })

    return response.ok({
      user: {
        id: user.id,
        email: user.email,
        name: user.name,
        emailVerified: user.emailVerified,
        pomodoroSettings: user.pomodoroSettings,
      },
      accessToken: accessToken.value!.release(),
      refreshToken: refreshToken.value!.release(),
    })
  }
  ```
- [ ] Add route: `router.post('/auth/login', [AuthController, 'login'])`
- [ ] Verify tokens have correct expiry: access 15min, refresh 7 days

### Task 9: Implement POST /v1/auth/refresh Endpoint (AC: 8)

- [ ] Implement `refresh` method in AuthController:
  ```typescript
  async refresh({ request, response, auth }: HttpContext) {
    const { refreshToken } = await request.validateUsing(refreshTokenValidator)

    try {
      const user = await auth.use('api').verifyToken(refreshToken)

      const newAccessToken = await User.accessTokens.create(user, ['*'], {
        expiresIn: '15 minutes',
      })

      return response.ok({
        accessToken: newAccessToken.value!.release(),
      })
    } catch (error) {
      return response.unauthorized({ error: 'Invalid refresh token' })
    }
  }
  ```

### Database Schema Overview

**Users Table:**
- UUID primary key (auto-generated)
- Email unique constraint
- Password hashed via bcrypt in `beforeSave` hook
- JSONB for pomodoro_settings (flexible schema)
- Timestamps for created_at/updated_at

**Tasks Table:**
- UUID primary key
- Foreign keys: user_id (required), project_id (nullable)
- Dual-status system: project_status, today_status (enables bidirectional sync in Phase 3)
- Soft deletes via deleted_at
- Indexes on user_id, project_id, today_status, deleted_at for query performance

[Source: docs/architecture.md#Data Models, Lines 438-531]

### Authentication Flow

1. **Registration:** POST /auth/register → Validate input → Hash password → Create user → Return user object (without password)
2. **Login:** POST /auth/login → Verify credentials → Generate access token (15min) + refresh token (7 days) → Return tokens + user
3. **Refresh:** POST /auth/refresh → Verify refresh token → Issue new access token → Return access token
4. **Logout:** POST /auth/logout → Invalidate refresh token → Return success

[Source: docs/architecture.md#API Specification, Lines 650-661]

### Security Requirements

- **Password Hashing:** bcrypt with cost factor 10+ (NFR7)
- **JWT Tokens:** 15-minute access, 7-day refresh (NFR8)
- **User Data Isolation:** All queries must filter by auth.user (NFR9)
- **Rate Limiting:** 5 req/min for auth endpoints (NFR10)
- **Input Validation:** VineJS validates all inputs (prevent SQL injection, XSS)

[Source: docs/prd.md#Non-Functional Requirements, Lines 127-132]

**Security:** Hash.make() uses bcrypt with cost factor 10+ by default in AdonisJS.

### JWT Token Strategy

- **Access Token:** Short-lived (15 minutes), sent with every request in `Authorization: Bearer <token>` header
- **Refresh Token:** Long-lived (7 days), used to obtain new access tokens without re-login
- **Storage:** Frontend stores both tokens (localStorage or secure cookie)
- **Middleware:** AuthMiddleware verifies access token on protected routes

[Source: docs/architecture.md#Authentication]

### User Data Isolation Pattern

**CRITICAL:** Every query must filter by authenticated user to prevent data leakage.

```typescript
// ✅ CORRECT
const tasks = await auth.user!.related('tasks').query().where('deleted_at', null)

// ❌ WRONG - Returns ALL users' tasks!
const tasks = await Task.query().where('deleted_at', null)
```

All routes require `auth` middleware. All queries scoped to `auth.user!`.
