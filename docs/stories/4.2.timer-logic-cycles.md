# Story 4.2: Timer Logic & Cycles

**Epic:** 4 - Pomodoro Timer (Focused Execution Tool)
**Story Number:** 4.2
**Status:** Ready for Review

---

## Story

**As a** user,
**I want** the timer to count down and cycle between focus and break,
**so that** I can follow Pomodoro technique automatically.

---

## Acceptance Criteria

1. Zustand pomodoroStore: timeRemaining, isRunning, mode, currentCycle, settings
2. Default settings: focusDuration 25min, breakDuration 5min, repetitions 3, autoSwitch true
3. setInterval decrements timeRemaining when isRunning
4. At 0: if autoSwitch and cycles remain, switch mode and start; else stop
5. currentCycle increments after each break
6. After configured repetitions, reset to initial state
7. MM:SS formatting correct
8. Progress ring percentage: (timeRemaining / totalDuration) * 100
9. Timer state persists in localStorage
10. Unit tests for countdown, mode switching, cycles

### Task 1: Create Pomodoro Store (AC: 1, 2, 9)

- [x] Create `apps/web/stores/pomodoroStore.ts`:
  ```typescript
  import { create } from 'zustand'
  import { persist } from 'zustand/middleware'

  interface PomodoroSettings {
    focusDuration: number // minutes
    breakDuration: number // minutes
    repetitions: number
    autoSwitch: boolean
  }

  interface PomodoroStore {
    // AC 1: State
    timeRemaining: number // seconds
    isRunning: boolean
    mode: 'focus' | 'break'
    currentCycle: number
    settings: PomodoroSettings

    // Actions
    setTimeRemaining: (time: number) => void
    setIsRunning: (running: boolean) => void
    setMode: (mode: 'focus' | 'break') => void
    setCurrentCycle: (cycle: number) => void
    updateSettings: (settings: Partial<PomodoroSettings>) => void
    tick: () => void // Decrement time
    reset: () => void
  }

  // AC 2: Default settings
  const defaultSettings: PomodoroSettings = {
    focusDuration: 25,
    breakDuration: 5,
    repetitions: 3,
    autoSwitch: true,
  }

  export const usePomodoroStore = create<PomodoroStore>()(
    persist(
      (set, get) => ({
        // AC 1: Initial state
        timeRemaining: 25 * 60, // 25 minutes in seconds
        isRunning: false,
        mode: 'focus',
        currentCycle: 1,
        settings: defaultSettings,

        setTimeRemaining: (time) => set({ timeRemaining: time }),
        setIsRunning: (running) => set({ isRunning: running }),
        setMode: (mode) => set({ mode }),
        setCurrentCycle: (cycle) => set({ currentCycle: cycle }),

        updateSettings: (newSettings) =>
          set((state) => ({
            settings: { ...state.settings, ...newSettings },
          })),

        // AC 3: Tick (decrement)
        tick: () => {
          const state = get()
          if (state.timeRemaining > 0) {
            set({ timeRemaining: state.timeRemaining - 1 })
          } else {
            // AC 4: Handle completion
            const { mode, currentCycle, settings } = state

            if (settings.autoSwitch) {
              if (mode === 'focus') {
                // Switch to break
                set({
                  mode: 'break',
                  timeRemaining: settings.breakDuration * 60,
                  isRunning: true,
                })
              } else {
                // Break completed
                // AC 5: Increment cycle
                const nextCycle = currentCycle + 1

                // AC 6: Check if all cycles completed
                if (nextCycle > settings.repetitions) {
                  // AC 6: Reset to initial state
                  set({
                    mode: 'focus',
                    timeRemaining: settings.focusDuration * 60,
                    currentCycle: 1,
                    isRunning: false,
                  })
                } else {
                  // Next focus cycle
                  set({
                    mode: 'focus',
                    timeRemaining: settings.focusDuration * 60,
                    currentCycle: nextCycle,
                    isRunning: true,
                  })
                }
              }
            } else {
              // AC 4: Auto-switch off, just stop
              set({ isRunning: false })
            }
          }
        },

        // AC 6: Reset
        reset: () =>
          set({
            timeRemaining: get().settings.focusDuration * 60,
            isRunning: false,
            mode: 'focus',
            currentCycle: 1,
          }),
      }),
      {
        name: 'pomodoro-storage', // AC 9: localStorage persistence
      }
    )
  )
  ```
- [x] AC 1: Complete store with all state
- [x] AC 2: Default settings (25min focus, 5min break, 3 reps, auto-switch)
- [x] AC 3: tick() decrements timeRemaining
- [x] AC 4: Auto-switch logic at 0
- [x] AC 5: Increment currentCycle after break
- [x] AC 6: Reset after all repetitions
- [x] AC 9: Zustand persist in localStorage

### Task 2: Implement Timer Countdown Logic (AC: 3)

- [x] Update `apps/web/components/pomodoro/PomodoroTimer.tsx`:
  ```typescript
  'use client'

  import { useEffect } from 'react'
  import { usePomodoroStore } from '@/stores/pomodoroStore'
  import { CircularTimer } from './CircularTimer'

  export function PomodoroTimer() {
    const {
      timeRemaining,
      isRunning,
      mode,
      currentCycle,
      settings,
      tick,
    } = usePomodoroStore()

    // AC 3: setInterval for countdown
    useEffect(() => {
      if (!isRunning) return

      const interval = setInterval(() => {
        tick() // AC 3: Decrement every second
      }, 1000)

      return () => clearInterval(interval)
    }, [isRunning, tick])

    // AC 7: MM:SS formatting
    const formatTime = (seconds: number): string => {
      const mins = Math.floor(seconds / 60)
      const secs = seconds % 60
      return `${mins.toString().padStart(2, '0')}:${secs.toString().padStart(2, '0')}`
    }

    // AC 8: Progress percentage
    const totalDuration = mode === 'focus'
      ? settings.focusDuration * 60
      : settings.breakDuration * 60

    const progressPercentage = (timeRemaining / totalDuration) * 100

    return (
      <div className="flex flex-col items-center justify-center space-y-8">
        <CircularTimer
          timeRemaining={timeRemaining}
          totalDuration={totalDuration}
          progressPercentage={progressPercentage}
          formattedTime={formatTime(timeRemaining)}
          mode={mode}
        />

        {/* Cycle indicator */}
        <div className="text-sm text-gray-600">
          Cycle {currentCycle} / {settings.repetitions}
        </div>

        {/* Controls will be added in Story 4.3 */}
      </div>
    )
  }
  ```

### Task 3: Write Unit Tests for Timer Logic (AC: 10)

- [x] Create `apps/web/stores/__tests__/pomodoroStore.test.ts`:
  ```typescript
  import { renderHook, act, waitFor } from '@testing-library/react'
  import { usePomodoroStore } from '../pomodoroStore'

  describe('Pomodoro Store - Timer Logic', () => {
    beforeEach(() => {
      // Reset store
      const { result } = renderHook(() => usePomodoroStore())
      act(() => {
        result.current.reset()
      })
    })

    // AC 3: Countdown
    it('decrements timeRemaining when tick is called', () => {
      const { result } = renderHook(() => usePomodoroStore())

      const initialTime = result.current.timeRemaining

      act(() => {
        result.current.tick()
      })

      expect(result.current.timeRemaining).toBe(initialTime - 1)
    })

    // AC 4: Auto-switch from focus to break
    it('switches from focus to break when time reaches 0', () => {
      const { result } = renderHook(() => usePomodoroStore())

      act(() => {
        result.current.setTimeRemaining(1)
        result.current.setMode('focus')
        result.current.setIsRunning(true)
      })

      // Tick to 0
      act(() => {
        result.current.tick()
      })

      // AC 4: Mode switched to break
      expect(result.current.mode).toBe('break')
      expect(result.current.timeRemaining).toBe(5 * 60) // 5 min break
      expect(result.current.isRunning).toBe(true) // Auto-switch keeps running
    })

    // AC 5: Increment cycle after break
    it('increments cycle after break completes', () => {
      const { result } = renderHook(() => usePomodoroStore())

      act(() => {
        result.current.setTimeRemaining(1)
        result.current.setMode('break')
        result.current.setCurrentCycle(1)
        result.current.setIsRunning(true)
      })

      // Complete break
      act(() => {
        result.current.tick()
      })

      // AC 5: Cycle incremented
      expect(result.current.currentCycle).toBe(2)
      expect(result.current.mode).toBe('focus')
    })

    // AC 6: Reset after all repetitions
    it('resets to initial state after all cycles complete', () => {
      const { result } = renderHook(() => usePomodoroStore())

      act(() => {
        result.current.setTimeRemaining(1)
        result.current.setMode('break')
        result.current.setCurrentCycle(3) // Last cycle
        result.current.setIsRunning(true)
      })

      // Complete last break
      act(() => {
        result.current.tick()
      })

      // AC 6: Reset to initial
      expect(result.current.currentCycle).toBe(1)
      expect(result.current.mode).toBe('focus')
      expect(result.current.isRunning).toBe(false) // Stops after all cycles
    })

    // AC 4: Auto-switch disabled
    it('stops timer at 0 when autoSwitch is false', () => {
      const { result } = renderHook(() => usePomodoroStore())

      act(() => {
        result.current.updateSettings({ autoSwitch: false })
        result.current.setTimeRemaining(1)
        result.current.setIsRunning(true)
      })

      act(() => {
        result.current.tick()
      })

      // AC 4: Stops, no mode switch
      expect(result.current.isRunning).toBe(false)
      expect(result.current.timeRemaining).toBe(0)
    })
  })
  ```

## Dev Notes

### Store Architecture (AC: 1)

**Zustand for timer state:**
- Global state (accessible anywhere)
- Persist middleware (survives refresh)
- Simple API (no boilerplate)

**State fields:**
- timeRemaining: seconds left
- isRunning: timer active?
- mode: focus or break
- currentCycle: 1, 2, 3
- settings: user preferences

### Default Settings (AC: 2)

**Classic Pomodoro:**
- 25 min focus
- 5 min break
- 3 repetitions
- Auto-switch enabled

**Why these values?**
- Research-backed (Cirillo method)
- Proven effective
- Industry standard

### Countdown Logic (AC: 3)

**setInterval vs requestAnimationFrame:**

**setInterval (chosen):**
```typescript
setInterval(() => tick(), 1000)
```
Runs every second, simple.

**requestAnimationFrame:**
```typescript
requestAnimationFrame(animate)
```
60 FPS, overkill for 1-second ticks.

**Decision:** setInterval for simplicity.

### Auto-Switch Logic (AC: 4)

**State machine:**
```
Focus (25min) → Break (5min) → Focus (25min) → Break → Focus → Break → STOP
   Cycle 1         Cycle 1        Cycle 2      Cycle 2  Cycle 3  Cycle 3
```

**At timeRemaining = 0:**
1. Check autoSwitch
2. If true: Switch mode, start next
3. If false: Stop

### Cycle Increment (AC: 5)

**Increment after break:**
```
Break ends → currentCycle++
```

**Why after break?**
- Cycle = focus + break
- Complete when break finishes

### Reset After Repetitions (AC: 6)

**Condition:**
```typescript
if (nextCycle > settings.repetitions)
```

**Action:**
```typescript
set({
  mode: 'focus',
  currentCycle: 1,
  isRunning: false, // Stop timer
  timeRemaining: settings.focusDuration * 60,
})
```

**User sees:**
Timer stops, shows 25:00, ready to restart.

### MM:SS Formatting (AC: 7)

**padStart(2, '0'):**
```
5 → "05"
25 → "25"
```

**Examples:**
- 1499s → 24:59
- 60s → 01:00
- 5s → 00:05

**Edge case: 0s:**
```
0 → "00:00"
```

### Progress Percentage (AC: 8)

**Formula:**
```typescript
(timeRemaining / totalDuration) * 100
```

**Examples:**
- 1500s / 1500s = 100% (full ring)
- 750s / 1500s = 50% (half ring)
- 0s / 1500s = 0% (empty ring)

**Ring depletes:**
100% → 0% as time counts down.

### localStorage Persistence (AC: 9)

**Zustand persist:**
```typescript
persist((set, get) => ({ ... }), { name: 'pomodoro-storage' })
```

**Automatic:**
- Save on every state change
- Load on page load
- Serialization handled

**localStorage structure:**
```json
{
  "pomodoro-storage": {
    "state": {
      "timeRemaining": 1499,
      "isRunning": true,
      "mode": "focus",
      "currentCycle": 1,
      "settings": { ... }
    },
    "version": 0
  }
}
```

### Testing Challenges (AC: 10)

**Time-dependent tests:**
```typescript
// Can't wait 25 minutes in test
it('completes full Pomodoro cycle', async () => {
  // Would take 25 + 5 + 25 + 5 + 25 + 5 = 90 minutes!
})
```

**Solution:**
Mock time or reduce durations.

**Story 4.3:**
Add mock timer for testing.

### Edge Case: Negative Time

**Should never happen:**
```typescript
if (timeRemaining > 0) {
  set({ timeRemaining: timeRemaining - 1 })
}
```

**Guard:**
Only decrement if > 0.

**At 0:**
Handle completion logic.

### Edge Case: Page Refresh Mid-Cycle

**Scenario:**
1. Start timer (25:00)
2. Run for 10 min (15:00 left)
3. Refresh page

**Expected:**
Timer shows 15:00, continues if isRunning.

**Actual:**
Zustand persist loads saved state.

**Works automatically.**

### Performance: setInterval Cleanup

**Memory leak prevention:**
```typescript
useEffect(() => {
  const interval = setInterval(...)
  return () => clearInterval(interval) // Cleanup
}, [isRunning])
```

**Critical:**
Without cleanup, multiple intervals run simultaneously.

### Cycle Indicator

**Shows progress:**
```
Cycle 1 / 3
Cycle 2 / 3
Cycle 3 / 3
```

**Helps user:**
Know how many cycles left.

### Auto-Switch User Control

**Setting:**
```typescript
autoSwitch: true // Default
```

**If disabled:**
Timer stops at 0, user manually starts next.

**Use case:**
User wants break before next cycle.
