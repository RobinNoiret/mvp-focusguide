# Story 3.4: Drag Tasks from Side Panel to Today

**Epic:** 3 - Connection Layer (Bridge Projects and Today with Bidirectional Sync)
**Story Number:** 3.4
**Status:** Draft

---

## Story

**As a** user,
**I want** to drag tasks from the project panel into Today,
**so that** I can schedule project tasks for daily execution.

---

## Acceptance Criteria

1. Panel task cards draggable via dnd-kit
2. Backlog, À faire aujourd'hui accept drops from panel
3. En cours, Done do NOT accept panel drops
4. Visual feedback during drag
5. Drop calls PATCH /v1/tasks/:id with today_status
6. Task appears in Today optimistically, remains in panel
7. Panel card gets "In Today" badge/icon
8. Multiple drops update today_status if different column
9. Backend allows project_id set + today_status set
10. Touch device support
11. Keyboard: "T" key adds to Today (column selector modal)
12. Rollback on failure
13. React Query invalidates Today cache

### Task 1: Make Today Columns Accept Drops from Panel (AC: 2, 3)

- [ ] Update `apps/web/components/today/TodayKanban.tsx`:
  ```typescript
  'use client'

  import { useState } from 'react'
  import {
    DndContext,
    DragOverlay,
    DragStartEvent,
    DragEndEvent,
    PointerSensor,
    useSensor,
    useSensors,
    closestCorners,
    DragOverEvent,
  } from '@dnd-kit/core'
  import { TodayColumn } from './TodayColumn'
  import { useUpdateTask } from '@/hooks/useUpdateTask'
  import type { Task, TodayStatus } from '@focus-guide/shared'

  export function TodayKanban() {
    const [activeTask, setActiveTask] = useState<Task | null>(null)
    const updateTask = useUpdateTask()
    const sensors = useSensors(useSensor(PointerSensor))

    const handleDragStart = (event: DragStartEvent) => {
      const task = event.active.data.current?.task
      setActiveTask(task || null)
    }

    const handleDragOver = (event: DragOverEvent) => {
      const { over, active } = event
      if (!over) return

      const task = active.data.current?.task as Task
      const overId = over.id as string

      // AC 3: Only allow drops in Backlog and À faire aujourd'hui
      const allowedColumns = ['backlog', 'todo']
      const isFromPanel = task?.project_id && !task.today_status

      if (isFromPanel && !allowedColumns.includes(overId)) {
        // Prevent drop (visual feedback in column)
        return
      }
    }

    const handleDragEnd = async (event: DragEndEvent) => {
      const { active, over } = event
      setActiveTask(null)

      if (!over) return

      const task = active.data.current?.task as Task
      const targetColumn = over.id as TodayStatus

      // AC 2: Backlog and todo accept panel task drops
      // AC 3: En cours and done do NOT accept
      const allowedColumns: TodayStatus[] = ['backlog', 'todo']
      const isFromPanel = task?.project_id && !task.today_status

      if (isFromPanel && !allowedColumns.includes(targetColumn)) {
        return // Ignore drop
      }

      // AC 5, 6: Update task with today_status
      await updateTask.mutateAsync({
        id: task.id,
        data: { today_status: targetColumn },
      })

      // AC 13: React Query invalidates Today cache (in mutation)
    }

    return (
      <DndContext
        sensors={sensors}
        collisionDetection={closestCorners}
        onDragStart={handleDragStart}
        onDragOver={handleDragOver}
        onDragEnd={handleDragEnd}
      >
        <div className="flex gap-6">
          <TodayColumn id="backlog" title="Backlog" acceptsPanelDrop />
          <TodayColumn id="todo" title="À faire aujourd'hui" acceptsPanelDrop />
          <TodayColumn id="in_progress" title="En cours" acceptsPanelDrop={false} />
          <TodayColumn id="done" title="Done" acceptsPanelDrop={false} />
        </div>

        {/* AC 4: Drag overlay for visual feedback */}
        <DragOverlay>
          {activeTask && <TaskCard task={activeTask} isDragging />}
        </DragOverlay>
      </DndContext>
    )
  }
  ```

### Task 3: Create useUpdateTask Hook (AC: 5, 6, 7, 12, 13)

- [ ] Create `apps/web/hooks/useUpdateTask.ts`:
  ```typescript
  import { useMutation, useQueryClient } from '@tanstack/react-query'
  import { taskService } from '@/services/taskService'
  import { useTodayStore } from '@/stores/todayStore'
  import type { UpdateTaskInput, Task } from '@focus-guide/shared'
  import { toast } from '@/hooks/use-toast'

  export function useUpdateTask() {
    const queryClient = useQueryClient()
    const { selectedProjectId } = useTodayStore()

    return useMutation({
      mutationFn: ({ id, data }: { id: string; data: UpdateTaskInput }) =>
        taskService.updateTask(id, data),

      // AC 6, 7: Optimistic update
      onMutate: async ({ id, data }) => {
        // Cancel outgoing queries
        await queryClient.cancelQueries({ queryKey: ['today'] })
        await queryClient.cancelQueries({ queryKey: ['projects', selectedProjectId] })

        // Snapshot previous values
        const previousToday = queryClient.getQueryData(['today'])
        const previousProject = queryClient.getQueryData(['projects', selectedProjectId])

        // AC 6: Task appears in Today optimistically
        if (data.today_status) {
          queryClient.setQueryData(['today'], (old: any) => {
            if (!old) return old

            // Check if task already in Today
            const existingTask = old.tasks?.find((t: Task) => t.id === id)

            if (existingTask) {
              // AC 8: Update today_status if different column
              return {
                ...old,
                tasks: old.tasks.map((t: Task) =>
                  t.id === id ? { ...t, today_status: data.today_status } : t
                ),
              }
            } else {
              // AC 6: Add task to Today
              // Need to fetch full task from project cache
              const projectTasks = previousProject?.tasks || []
              const taskToAdd = projectTasks.find((t: Task) => t.id === id)

              if (taskToAdd) {
                return {
                  ...old,
                  tasks: [
                    ...(old.tasks || []),
                    { ...taskToAdd, today_status: data.today_status },
                  ],
                }
              }
            }

            return old
          })
        }

        // AC 7: Panel card gets "Dans Today" badge
        // Update project cache to show task is in Today
        queryClient.setQueryData(['projects', selectedProjectId], (old: any) => {
          if (!old) return old

          return {
            ...old,
            tasks: old.tasks?.map((t: Task) =>
              t.id === id ? { ...t, today_status: data.today_status } : t
            ),
          }
        })

        return { previousToday, previousProject }
      },

      // AC 12: Rollback on error
      onError: (err, variables, context) => {
        queryClient.setQueryData(['today'], context?.previousToday)
        queryClient.setQueryData(
          ['projects', selectedProjectId],
          context?.previousProject
        )

        toast({
          title: 'Erreur',
          description: 'Impossible d\'ajouter la tâche à Today. Veuillez réessayer.',
          variant: 'destructive',
        })
      },

      // AC 13: Invalidate caches
      onSuccess: () => {
        queryClient.invalidateQueries({ queryKey: ['today'] })
        queryClient.invalidateQueries({ queryKey: ['projects', selectedProjectId] })

        toast({
          title: 'Succès',
          description: 'Tâche ajoutée à Today',
        })
      },
    })
  }
  ```
- [ ] AC 5: PATCH /v1/tasks/:id with today_status
- [ ] AC 6: Task appears in Today optimistically
- [ ] AC 7: Update project cache (badge appears)
- [ ] AC 8: Handle multiple drops (update today_status)
- [ ] AC 12: Rollback on failure
- [ ] AC 13: Invalidate both caches

## Dev Notes

### Dual Cache Update (AC 6, 7)

**Challenge:**
Task exists in TWO caches:
1. `['today']` - Today page tasks
2. `['projects', projectId]` - Project tasks

**Optimistic update:**
```typescript
// Add to Today
queryClient.setQueryData(['today'], ...)

// Update panel (badge appears)
queryClient.setQueryData(['projects', projectId], ...)
```

**Both must succeed or both fail (rollback).**

### "Dans Today" Badge (AC 7)

**Condition:**
```typescript
task.today_status !== null
```

**Chartreuse badge:**
```typescript
<span className="bg-[#D9FC0030]">Dans Today</span>
```

**User benefit:**
Prevents adding task twice.

### Allowed Drop Zones (AC 2, 3)

**Why only Backlog and À faire aujourd'hui?**
- New tasks start in planning stage
- "En cours" = actively working (requires manual transition)
- "Done" = completed (shouldn't add new tasks)

**Visual feedback:**
- Valid: Chartreuse border
- Invalid: Red border + helper text

### Multiple Drops (AC 8)

**Scenario:**
1. Drag task to Backlog → `today_status: 'backlog'`
2. Drag same task to À faire → `today_status: 'todo'`

**Result:**
Task moves columns in Today.

**Backend:**
```typescript
PATCH /v1/tasks/:id
{ "today_status": "todo" }
```

Overwrites previous value.

### Backend Constraint Check (AC 9)

**Database schema:**
```sql
tasks (
  id UUID,
  project_id UUID NULLABLE,
  today_status ENUM NULLABLE
)
```

**No constraint:**
Both can be set simultaneously.

**This is the core feature:**
Task lives in Project AND Today.

### Touch Device Support (AC 10)

**Challenge:**
Drag vs scroll on mobile.

**Solution:**
```typescript
activationConstraint: {
  delay: 250, // Long press
  tolerance: 5, // Pixels before drag
}
```

**User experience:**
- Quick touch: Scroll
- Long press: Drag

### Keyboard Alternative (AC 11)

**Why needed?**
- Motor disabilities
- Keyboard-only users
- Accessibility requirement

**"T" key:**
- Mnemonic: **T**oday
- Easy to remember
- Single key (not Ctrl+T)

**Modal:**
Clear, focused interaction.

### Rollback Complexity (AC 12)

**Three caches:**
1. Today tasks
2. Project tasks
3. (Future) All projects list

**All must rollback:**
```typescript
onError: (err, vars, context) => {
  queryClient.setQueryData(['today'], context.previousToday)
  queryClient.setQueryData(['projects', id], context.previousProject)
}
```

**User experience:**
Task disappears from Today, badge removed from panel.

### Cache Invalidation (AC 13)

**Why invalidate?**
Optimistic update may differ from server.

**When:**
After successful mutation.

**What:**
```typescript
queryClient.invalidateQueries(['today'])
queryClient.invalidateQueries(['projects', selectedProjectId])
```

**Result:**
Refetch from server (authoritative data).
