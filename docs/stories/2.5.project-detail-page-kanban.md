# Story 2.5: Project Detail Page with Kanban

**Epic:** 2 - Projects Management (Strategic Planning Layer)
**Story Number:** 2.5
**Status:** Ready for Review

---

## Story

**As a** user,
**I want** to view a project's tasks in a kanban,
**so that** I can manage the project workflow.

---

## Acceptance Criteria

1. Project detail route (/projects/:id)
2. Header: title, back arrow, info icon, Kanban/Gantt toggle
3. 4-column kanban: Backlog, To do, In progress, Done (Done vertical on right)
4. React Query useProject(id) fetches project with tasks
5. Tasks grouped by project_status
6. Task cards styled like Today
7. Empty columns: "Aucune tâche"
8. "Add task" button per column
9. Info icon opens settings modal
10. Back arrow navigates to /projects
11. Loading: skeleton kanban
12. Error: 404 page
13. Responsive layout

---

### Task 2: Create useProject Hook (AC: 4)

  ```typescript
  import { useQuery } from '@tanstack/react-query'
  import { projectService } from '@/services/projectService'
  import type { ProjectWithStats } from '@focus-guide/shared'

  export function useProject(projectId: string) {
    return useQuery<ProjectWithStats>({
      queryKey: ['projects', projectId],
      queryFn: () => projectService.getProject(projectId),
      staleTime: 1000 * 60 * 5, // 5 minutes
      refetchOnWindowFocus: true,
      retry: 1, // Only retry once for 404
    })
  }
  ```

### Task 4: Create ProjectKanban Component (AC: 3, 5, 6, 7, 8)

- [ ] Create `apps/web/components/projects/ProjectKanban.tsx`:
  ```typescript
  'use client'

  import { useMemo } from 'react'
  import { Plus } from 'lucide-react'
  import { ProjectTaskCard } from './ProjectTaskCard'
  import { Button } from '@/components/ui/button'
  import type { ProjectWithStats, Task } from '@focus-guide/shared'

  type ProjectStatus = 'backlog' | 'todo' | 'in_progress' | 'done'

  interface ProjectKanbanProps {
    project: ProjectWithStats
  }

  export function ProjectKanban({ project }: ProjectKanbanProps) {
    // AC 5: Tasks grouped by project_status
    const tasksByStatus = useMemo(() => {
      const groups: Record<ProjectStatus, Task[]> = {
        backlog: [],
        todo: [],
        in_progress: [],
        done: [],
      }

      project.tasks?.forEach((task) => {
        if (task.project_status && !task.deleted_at) {
          groups[task.project_status as ProjectStatus].push(task)
        }
      })

      return groups
    }, [project.tasks])

    // AC 3: 4-column kanban
    const columns: Array<{
      id: ProjectStatus
      title: string
      tasks: Task[]
    }> = [
      { id: 'backlog', title: 'Backlog', tasks: tasksByStatus.backlog },
      { id: 'todo', title: 'To do', tasks: tasksByStatus.todo },
      { id: 'in_progress', title: 'In progress', tasks: tasksByStatus.in_progress },
      { id: 'done', title: 'Done', tasks: tasksByStatus.done },
    ]

    return (
      <div className="flex gap-6">
        {/* First 3 columns: Horizontal layout */}
        {columns.slice(0, 3).map((column) => (
          <KanbanColumn
            key={column.id}
            column={column}
            projectId={project.id}
            vertical={false}
          />
        ))}

        {/* AC 3: Done column vertical on right */}
        <KanbanColumn
          column={columns[3]}
          projectId={project.id}
          vertical={true}
        />
      </div>
    )
  }

  interface KanbanColumnProps {
    column: {
      id: ProjectStatus
      title: string
      tasks: Task[]
    }
    projectId: string
    vertical: boolean
  }

  function KanbanColumn({ column, projectId, vertical }: KanbanColumnProps) {
    return (
      <div
        className={`flex ${
          vertical ? 'w-64 flex-col' : 'flex-1 flex-col'
        } rounded-lg bg-white p-4 shadow-sm`}
      >
        {/* Column header */}
        <div className="mb-4 flex items-center justify-between">
          <h3 className="text-sm font-semibold uppercase tracking-wide text-gray-600">
            {column.title}
            <span className="ml-2 rounded-full bg-gray-200 px-2 py-0.5 text-xs">
              {column.tasks.length}
            </span>
          </h3>

          {/* AC 8: "Add task" button per column */}
          <button
            className="rounded p-1 hover:bg-gray-100"
            aria-label={`Ajouter une tâche à ${column.title}`}
          >
            <Plus className="h-4 w-4 text-gray-600" />
          </button>
        </div>

        {/* Tasks list */}
        <div className={`space-y-3 ${vertical ? 'flex-1 overflow-y-auto' : ''}`}>
          {/* AC 7: Empty state */}
          {column.tasks.length === 0 ? (
            <p className="py-8 text-center text-sm text-gray-400">
              Aucune tâche
            </p>
          ) : (
            column.tasks.map((task) => (
              <ProjectTaskCard
                key={task.id}
                task={task}
                projectId={projectId}
              />
            ))
          )}
        </div>
      </div>
    )
  }
  ```
- [ ] 4-column kanban: Backlog, To do, In progress, Done (AC 3)

  ```typescript
  'use client'

  import { useEffect } from 'react'
  import { useForm } from 'react-hook-form'
  import { zodResolver } from '@hookform/resolvers/zod'
  import { z } from 'zod'
  import {
    Dialog,
    DialogContent,
    DialogHeader,
    DialogTitle,
    DialogFooter,
  } from '@/components/ui/dialog'
  import { Button } from '@/components/ui/button'
  import { Input } from '@/components/ui/input'
  import { Textarea } from '@/components/ui/textarea'
  import { Label } from '@/components/ui/label'
  import { DatePicker } from '@/components/ui/date-picker'
  import { TagInput } from '@/components/ui/tag-input'
  import { useUpdateProject } from '@/hooks/useUpdateProject'
  import type { ProjectWithStats } from '@focus-guide/shared'

  const projectSettingsSchema = z.object({
    title: z.string().min(1).max(200),
    description: z.string().max(2000).optional(),
    deadline: z.date().nullable().optional(),
    tags: z.array(z.string()).max(10).optional(),
  })

  type ProjectSettingsFormData = z.infer<typeof projectSettingsSchema>

  interface ProjectSettingsModalProps {
    isOpen: boolean
    onClose: () => void
    project: ProjectWithStats
  }

  export function ProjectSettingsModal({
    isOpen,
    onClose,
    project,
  }: ProjectSettingsModalProps) {
    const updateProject = useUpdateProject()

    const {
      register,
      handleSubmit,
      formState: { errors },
      setValue,
      watch,
      reset,
    } = useForm<ProjectSettingsFormData>({
      resolver: zodResolver(projectSettingsSchema),
    })

    // Pre-fill form with project data
    useEffect(() => {
      if (project) {
        reset({
          title: project.title,
          description: project.description || '',
          deadline: project.deadline ? new Date(project.deadline) : null,
          tags: project.tags || [],
        })
      }
    }, [project, reset])

    const onSubmit = async (data: ProjectSettingsFormData) => {
      await updateProject.mutateAsync({
        id: project.id,
        data: {
          title: data.title,
          description: data.description,
          deadline: data.deadline?.toISOString().split('T')[0],
          tags: data.tags,
        },
      })
      onClose()
    }

    return (
      <Dialog open={isOpen} onOpenChange={onClose}>
        <DialogContent className="sm:max-w-[600px]">
          <DialogHeader>
            <DialogTitle className="text-2xl font-bold text-[#262626]">
              Paramètres du projet
            </DialogTitle>
          </DialogHeader>

          <form onSubmit={handleSubmit(onSubmit)}>
            <div className="space-y-6 py-4">
              {/* Title */}
              <div className="space-y-2">
                <Label htmlFor="settings-title">Titre</Label>
                <Input
                  id="settings-title"
                  {...register('title')}
                  className={errors.title ? 'border-red-500' : ''}
                />
                {errors.title && (
                  <p className="text-sm text-red-500">{errors.title.message}</p>
                )}
              </div>

              {/* Description */}
              <div className="space-y-2">
                <Label htmlFor="settings-description">Description</Label>
                <Textarea
                  id="settings-description"
                  {...register('description')}
                  rows={4}
                  className={errors.description ? 'border-red-500' : ''}
                />
              </div>

              {/* Deadline */}
              <div className="space-y-2">
                <Label htmlFor="settings-deadline">Échéance</Label>
                <DatePicker
                  date={watch('deadline')}
                  onDateChange={(date) => setValue('deadline', date)}
                  accentColor="#D9FC00"
                />
              </div>

              {/* Tags */}
              <div className="space-y-2">
                <Label htmlFor="settings-tags">Tags</Label>
                <TagInput
                  tags={watch('tags') || []}
                  onTagsChange={(tags) => setValue('tags', tags)}
                  maxTags={10}
                />
              </div>

              {/* Project stats (read-only) */}
              <div className="rounded-lg bg-gray-50 p-4">
                <h4 className="mb-3 font-semibold text-[#262626]">Statistiques</h4>
                <div className="grid grid-cols-2 gap-4 text-sm">
                  <div>
                    <p className="text-gray-600">Tâches totales</p>
                    <p className="text-lg font-bold text-[#262626]">
                      {project.task_count}
                    </p>
                  </div>
                  <div>
                    <p className="text-gray-600">Progression</p>
                    <p className="text-lg font-bold text-[#262626]">
                      {project.completion_percentage}%
                    </p>
                  </div>
                  <div>
                    <p className="text-gray-600">Terminées</p>
                    <p className="text-lg font-bold text-[#262626]">
                      {project.task_counts?.done || 0}
                    </p>
                  </div>
                  <div>
                    <p className="text-gray-600">En cours</p>
                    <p className="text-lg font-bold text-[#262626]">
                      {project.task_counts?.in_progress || 0}
                    </p>
                  </div>
                </div>
              </div>
            </div>

            <DialogFooter>
              <Button
                type="button"
                variant="outline"
                onClick={onClose}
              >
                Annuler
              </Button>
              <Button
                type="submit"
                className="bg-[#D9FC00] text-[#262626] hover:bg-[#c4e600]"
                disabled={updateProject.isPending}
              >
                {updateProject.isPending ? 'Enregistrement...' : 'Enregistrer'}
              </Button>
            </DialogFooter>
          </form>
        </DialogContent>
      </Dialog>
  ```

### useProject Hook vs useProjects

**Two separate hooks:**
1. `useProjects()` - GET /v1/projects (list)
2. `useProject(id)` - GET /v1/projects/:id (single with tasks)

**Cache keys:**
```typescript
['projects'] // List cache
['projects', id] // Single project cache
```

**Why separate?**
- Different data shape (list vs detail)
- Different refresh strategies
- Easier invalidation (update one doesn't invalidate list)

**Cache synchronization:**
When project updated in detail view, invalidate both:
```typescript
onSuccess: () => {
  queryClient.invalidateQueries(['projects'])
  queryClient.invalidateQueries(['projects', id])
}
```

All columns stretch to container height.

### Task Grouping by project_status

**Grouping logic:**
```typescript
const tasksByStatus = useMemo(() => {
  const groups = { backlog: [], todo: [], in_progress: [], done: [] }

  project.tasks?.forEach(task => {
    if (task.project_status && !task.deleted_at) {
      groups[task.project_status].push(task)
    }
  })

  return groups
}, [project.tasks])
```

**useMemo optimization:**
- Only recalculate when `project.tasks` changes
- Avoids re-grouping on every render
- Important for large task lists

**Filter deleted tasks:**
```typescript
if (task.project_status && !task.deleted_at)
```

Soft-deleted tasks excluded from kanban.

### Performance: useMemo for Grouping

**Task grouping can be expensive:**

- Re-render on every state change

- With useMemo: ~0.1ms per render (cached)

Noticeable on slower devices.

### Cache Invalidation Strategy

2. Task updated → invalidate `['projects', id]`

**Why invalidate both?**
- `['projects', id]`: Refresh detail view (task counts updated)
- `['projects']`: Refresh grid view (completion % updated)

**Alternative: Optimistic update both caches**
More complex, but fewer API calls. Can optimize post-MVP.
