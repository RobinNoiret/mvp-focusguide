# Story 3.2: Project Selector in Side Panel

**Epic:** 3 - Connection Layer (Bridge Projects and Today with Bidirectional Sync)
**Story Number:** 3.2
**Status:** Draft

---

## Story

**As a** user,
**I want** to select a project from the side panel dropdown,
**so that** I can see tasks from that project.

---

## Acceptance Criteria

1. Dropdown fetches projects from GET /v1/projects
2. Populates with project titles (alphabetical)
3. Selection updates todayStore.selectedProjectId
4. Persists in localStorage across refreshes
5. Shows current project: "Projet - [Name]"
6. "Aucun projet sélectionné" option to clear
7. Loading state in dropdown
8. Empty state: "Aucun projet disponible..."
9. Click outside closes dropdown
10. Keyboard: arrows, Enter, Escape

### Task 1: Create ProjectSelectorDropdown Component (AC: 1, 2, 5, 6, 7, 8, 9, 10)

- [ ] Create `apps/web/components/today/ProjectSelectorDropdown.tsx`:
  ```typescript
  'use client'

  import { useState } from 'react'
  import { Check, ChevronDown, X } from 'lucide-react'
  import {
    Command,
    CommandEmpty,
    CommandGroup,
    CommandInput,
    CommandItem,
    CommandList,
  } from '@/components/ui/command'
  import {
    Popover,
    PopoverContent,
    PopoverTrigger,
  } from '@/components/ui/popover'
  import { Button } from '@/components/ui/button'
  import { useProjects } from '@/hooks/useProjects'
  import { useTodayStore } from '@/stores/todayStore'
  import { cn } from '@/lib/utils'

  export function ProjectSelectorDropdown() {
    const [open, setOpen] = useState(false)
    const { data: projects, isLoading } = useProjects() // AC 1
    const { selectedProjectId, setSelectedProjectId } = useTodayStore() // AC 3

    // Find selected project name
    const selectedProject = projects?.find((p) => p.id === selectedProjectId)
    const selectedProjectName = selectedProject?.title

    // AC 2: Sort projects alphabetically
    const sortedProjects = projects
      ?.slice()
      .sort((a, b) => a.title.localeCompare(b.title, 'fr'))

    const handleSelect = (projectId: string | null) => {
      // AC 3: Update store
      setSelectedProjectId(projectId)
      setOpen(false)
    }

    return (
      <Popover open={open} onOpenChange={setOpen}>
        <PopoverTrigger asChild>
          <Button
            variant="outline"
            role="combobox"
            aria-expanded={open}
            aria-label="Sélectionner un projet"
            className="w-full justify-between font-medium text-[#262626] hover:border-gray-300 focus:border-[#D9FC00] focus:ring-2 focus:ring-[#D9FC00]"
          >
            {/* AC 5: Show current project name */}
            <span className="truncate">
              {selectedProjectName
                ? `Projet - ${selectedProjectName}`
                : 'Projet - Sélectionner'}
            </span>
            <ChevronDown className="ml-2 h-4 w-4 shrink-0 opacity-50" />
          </Button>
        </PopoverTrigger>

        {/* AC 9: Click outside closes */}
        <PopoverContent className="w-80 p-0" align="start">
          <Command>
            <CommandInput
              placeholder="Rechercher un projet..."
              className="h-9"
            />
            <CommandList>
              {/* AC 7: Loading state */}
              {isLoading && (
                <div className="py-6 text-center text-sm text-gray-500">
                  Chargement...
                </div>
              )}

              {/* AC 8: Empty state */}
              {!isLoading && (!sortedProjects || sortedProjects.length === 0) && (
                <CommandEmpty>Aucun projet disponible...</CommandEmpty>
              )}

              {!isLoading && sortedProjects && sortedProjects.length > 0 && (
                <CommandGroup>
                  {/* AC 6: Clear selection option */}
                  <CommandItem
                    value="none"
                    onSelect={() => handleSelect(null)}
                    className="cursor-pointer"
                  >
                    <X className="mr-2 h-4 w-4 text-gray-500" />
                    <span className="text-gray-600">Aucun projet sélectionné</span>
                    {!selectedProjectId && (
                      <Check className="ml-auto h-4 w-4 text-[#D9FC00]" />
                    )}
                  </CommandItem>

                  {/* AC 2: Project list (alphabetical) */}
                  {sortedProjects.map((project) => (
                    <CommandItem
                      key={project.id}
                      value={project.title}
                      onSelect={() => handleSelect(project.id)}
                      className="cursor-pointer"
                    >
                      <div className="flex flex-1 items-center justify-between">
                        <div className="flex-1 truncate">
                          <div className="font-medium text-[#262626]">
                            {project.title}
                          </div>
                          {project.description && (
                            <div className="text-xs text-gray-500 truncate">
                              {project.description}
                            </div>
                          )}
                        </div>
                        {/* Task count badge */}
                        <div className="ml-2 flex items-center gap-2">
                          <span className="text-xs text-gray-500">
                            {project.task_count || 0}
                          </span>
                          {selectedProjectId === project.id && (
                            <Check className="h-4 w-4 text-[#D9FC00]" />
                          )}
                        </div>
                      </div>
                    </CommandItem>
                  ))}
                </CommandGroup>
              )}
            </CommandList>
          </Command>
        </PopoverContent>
      </Popover>
    )
  }
  ```

  ```typescript
  import { create } from 'zustand'
  import { persist } from 'zustand/middleware'

  interface TodayStore {
    selectedProjectId: string | null
    setSelectedProjectId: (projectId: string | null) => void
  }

  // AC 3, 4: Store with localStorage persistence
  export const useTodayStore = create<TodayStore>()(
    persist(
      (set) => ({
        selectedProjectId: null,

        setSelectedProjectId: (projectId) => {
          set({ selectedProjectId: projectId })
        },
      }),
      {
        name: 'today-storage', // AC 4: localStorage key
      }
    )
  )
  ```

## Dev Notes

### Alphabetical Sorting (AC 2)

**Why alphabetical?**
- Predictable order
- Easy to scan for users
- Standard UX pattern

**French locale:**
```typescript
.sort((a, b) => a.title.localeCompare(b.title, 'fr'))
```

Handles accented characters correctly:
- "École" before "Écran"
- "Été" before "Étudiant"

### Zustand Persist Middleware (AC 4)

**localStorage structure:**
```json
{
  "today-storage": {
    "state": {
      "selectedProjectId": "project-123"
    },
    "version": 0
  }
}
```

**Automatic:**
- Serialization on update
- Deserialization on load
- Version migration support

**Benefits:**
- Survives page refresh
- Survives browser restart
- No manual localStorage management

### Command Component for Dropdown

**Why Command over Select?**
- Built-in search/filter
- Keyboard navigation (arrows, Enter, Escape)
- ARIA attributes for accessibility
- Better UX for long lists

**Features:**
- `CommandInput`: Search box
- `CommandList`: Scrollable list
- `CommandItem`: Selectable items
- `CommandEmpty`: Empty state
- `CommandGroup`: Item grouping

### Clear Selection Option (AC 6)

**Why "Aucun projet sélectionné"?**
- User may want to view Today without projects
- Explicit action (not accidental)
- Consistent with other dropdowns

**Icon:**
X icon (clear/remove indication)

**Position:**
Top of list (always visible, doesn't scroll away)

### Loading State (AC 7)

**When shown:**
- Initial page load (projects fetching)
- After login redirect
- Manual refetch (rare)

**Duration:**
Typically < 200ms (API NFR requirement)

**Prevents:**
- Empty state flash
- Flickering dropdown
- Confusing user

### Empty State (AC 8)

**When shown:**
- User has no projects yet
- All projects deleted

**Message:**
"Aucun projet disponible..."

**Action:**
User should create a project first.

**Future enhancement:**
Add CTA: "Créer votre premier projet" link.

### Click Outside to Close (AC 9)

**Popover handles automatically:**
```typescript
<Popover onOpenChange={setOpen}>
  {/* Clicking outside triggers setOpen(false) */}
</Popover>
```

**Backdrop:**
Invisible overlay captures click outside.

**User experience:**
Natural dismissal pattern.

### Keyboard Navigation (AC 10)

**Command component keyboard:**
- **Tab:** Focus dropdown button
- **Enter/Space:** Open dropdown
- **Arrow Down/Up:** Navigate items
- **Enter:** Select item
- **Escape:** Close dropdown

**Accessibility:**
Full keyboard control, no mouse required.

### Store Design Philosophy

**Single responsibility:**
```typescript
interface TodayStore {
  selectedProjectId: string | null
  setSelectedProjectId: (projectId: string | null) => void
}
```

Only manages selected project.

**Future expansion:**
```typescript
interface TodayStore {
  selectedProjectId: string | null
  setSelectedProjectId: (projectId: string | null) => void
  filterStatus: TodayStatus | null // Future: Filter by status
  searchQuery: string // Future: Search tasks
}
```

But for now, keep it simple.

### Persistence Key Naming

**"today-storage"**

**Why this name?**
- Descriptive (related to Today page)
- Namespaced (won't conflict)
- Consistent pattern

**Other stores:**
- "auth-storage" (auth tokens)
- "settings-storage" (user preferences)
- "pomodoro-storage" (timer settings)

### Performance: Sorting Projects

**Concern:**
Sorting on every render?

**Solution:**
```typescript
const sortedProjects = useMemo(() => {
  return projects?.slice().sort(...)
}, [projects])
```

**But:**
Command component handles filtering/sorting internally.
