**Epic:** 2 - Projects Management (Strategic Planning Layer)
**Story Number:** 2.3
**Status:** Ready for Review

---

## Story

**As a** user,
**I want** to view all my projects in a grid,
**so that** I can see an overview and navigate to projects.

---

## Acceptance Criteria

1. Projects page route (/projects or /projets) with protected route
2. Header: "Mes projets" title, "Gérer les projets" button, grid/list toggle
3. Grid: 3 columns (2 on tablet, 1 on mobile)
4. Each card shows: title, description (truncated), deadline, task count, category badge, progress bar, three-dot menu
5. Empty state: "Aucun projet" with CTA button
6. React Query useProjects() hook
7. Loading: skeleton cards
8. Error: message with retry
9. Clicking card navigates to /projects/:id
10. Grid styled per mockup
11. "Projets" active in sidebar

  interface ProjectCardProps {

      // Don't navigate if clicking three-dot menu

      router.push(`/projets/${project.id}`) // AC 9

    const getProgressBarColor = (percentage: number) => {
      if (percentage === 0) return 'bg-gray-300'
      if (percentage < 30) return 'bg-[#FF4D4D]' // Red
      if (percentage < 70) return 'bg-[#FFD700]' // Yellow
      if (percentage < 100) return 'bg-[#00D4D4]' // Cyan
      return 'bg-[#40E0D0]' // Turquoise
    }

    return (
      <div
        onClick={handleCardClick}
        className="cursor-pointer rounded-lg bg-white p-6 shadow-sm transition-shadow hover:shadow-md"
      >
        {/* Header with title and three-dot menu (AC 4) */}
        <div className="mb-3 flex items-start justify-between">
          <h3 className="text-lg font-semibold text-[#262626]">
            {project.title}
          </h3>

          {/* Three-dot menu (AC 4) */}
          <DropdownMenu>
            <DropdownMenuTrigger data-dropdown-trigger asChild>
              <button className="rounded p-1 hover:bg-gray-100">
                <MoreVertical className="h-5 w-5 text-gray-600" />
              </button>
            </DropdownMenuTrigger>
            <DropdownMenuContent align="end">
              <DropdownMenuItem>Modifier</DropdownMenuItem>
              <DropdownMenuItem className="text-red-600">
                Supprimer
              </DropdownMenuItem>
            </DropdownMenuContent>
          </DropdownMenu>
        </div>

        {/* Description (truncated) (AC 4) */}
        {project.description && (
          <p className="mb-4 line-clamp-2 text-sm text-gray-600">
            {project.description}
          </p>
        )}

        {/* Deadline (AC 4) */}
        {project.deadline && (
          <div className="mb-3 flex items-center gap-2 text-sm text-gray-500">
            <Calendar className="h-4 w-4" />
            <span>
              Échéance:{' '}
              {format(new Date(project.deadline), 'dd/MM/yyyy', { locale: fr })}
            </span>
          </div>
        )}

        {/* Category badge (tags) (AC 4) */}
        {project.tags && project.tags.length > 0 && (
          <div className="mb-3 flex flex-wrap gap-2">
            {project.tags.slice(0, 3).map((tag, index) => (
              <span
                key={index}
                className="rounded-full bg-gray-100 px-3 py-1 text-xs text-gray-700"
              >
                {tag}
              </span>
            ))}
            {project.tags.length > 3 && (
              <span className="rounded-full bg-gray-100 px-3 py-1 text-xs text-gray-700">
                +{project.tags.length - 3}
              </span>
            )}
          </div>
        )}

        {/* Task count (AC 4) */}
        <p className="mb-2 text-sm text-gray-600">
          {project.task_counts?.done || 0}/{project.task_count || 0} tâches
        </p>

        {/* Progress bar (AC 4) */}
        <div className="h-2 w-full overflow-hidden rounded-full bg-gray-200">
          <div
            className={`h-full transition-all ${getProgressBarColor(
              project.completion_percentage
            )}`}
            style={{ width: `${project.completion_percentage}%` }}
          />
        </div>
        <p className="mt-1 text-right text-xs text-gray-500">
          {project.completion_percentage}%
        </p>
      </div>
    )
  }

### Task 7: Configure API Client with Projects Endpoint

- [ ] Verify `apps/web/lib/apiClient.ts` configured:
  ```typescript
  import axios from 'axios'
  import { getToken, refreshToken } from '@/lib/auth'

  export const apiClient = axios.create({
    baseURL: process.env.NEXT_PUBLIC_API_URL || 'http://localhost:3333',
    headers: {
      'Content-Type': 'application/json',
    },
  })

  // Request interceptor: Add auth token
  apiClient.interceptors.request.use(
    async (config) => {
      const token = await getToken()
      if (token) {
        config.headers.Authorization = `Bearer ${token}`
      }
      return config
    },
    (error) => Promise.reject(error)
  )

  // Response interceptor: Handle 401, refresh token
  apiClient.interceptors.response.use(
    (response) => response,
    async (error) => {
      const originalRequest = error.config

      if (error.response?.status === 401 && !originalRequest._retry) {
        originalRequest._retry = true

        try {
          const newToken = await refreshToken()
          originalRequest.headers.Authorization = `Bearer ${newToken}`
          return apiClient(originalRequest)
        } catch (refreshError) {
          // Redirect to login
          window.location.href = '/login'
          return Promise.reject(refreshError)
        }
      }

      return Promise.reject(error)
    }
  )
  ```

## Dev Notes

### React Query Cache Strategy

**Why React Query for projects?**

React Query provides:
- ✅ Automatic caching (reduces API calls)
- ✅ Background refetch (data stays fresh)
- ✅ Loading and error states built-in
- ✅ Optimistic updates (Story 2.4)
- ✅ Request deduplication (multiple components, one request)

**Cache configuration:**
```typescript
{
  queryKey: ['projects'],
  staleTime: 1000 * 60 * 5, // 5 minutes
  refetchOnWindowFocus: true,
}
```

**Cache behavior:**
- Fresh data for 5 minutes (no refetch)
- After 5 minutes: stale, refetches in background
- Window focus: automatic refetch (user returns to tab)
- Manual refetch: `refetch()` button on error

**Why 5 minutes?**
- Projects change infrequently (not like real-time chat)
- Balance: Freshness vs API load
- Can be tuned based on user feedback

**Query invalidation:**
Story 2.4 (create/edit project) will invalidate cache:
```typescript
onSuccess: () => {
  queryClient.invalidateQueries({ queryKey: ['projects'] })
}
```

### Grid Layout Implementation

**Responsive grid with Tailwind CSS:**
```css
grid-cols-1          /* Mobile: 1 column */
md:grid-cols-2       /* Tablet (768px+): 2 columns */
lg:grid-cols-3       /* Desktop (1024px+): 3 columns */
```

**Why CSS Grid over Flexbox?**
- ✅ Explicit column control (exactly 3 columns)
- ✅ Auto-fill rows (cards flow naturally)
- ✅ Equal-height cards (grid tracks)
- ✅ Gap spacing (no margin math)

**Alternative: Flexbox with flex-wrap**
```css
flex flex-wrap gap-6
flex-1 min-w-[300px] max-w-[400px]
```
Pros: More flexible
Cons: Hard to guarantee exactly N columns

For fixed-column grid, CSS Grid is superior.

### Progress Bar Color Logic

  if (percentage < 100) return 'bg-[#00D4D4]'

### Navigation Event Handling

**Problem:** Three-dot menu inside card
- Click card → navigate
- Click menu → open dropdown (don't navigate)

**Solution:** Event target check
```typescript
const handleCardClick = (e: React.MouseEvent) => {
  if ((e.target as HTMLElement).closest('[data-dropdown-trigger]')) {
    return // Don't navigate
  }
  router.push(`/projets/${project.id}`)
}
```

**How it works:**
1. User clicks card → navigate
2. User clicks menu → `closest('[data-dropdown-trigger]')` finds trigger → return early
3. Menu opens, no navigation

**Alternative:** `e.stopPropagation()` in menu
```typescript
<button onClick={(e) => e.stopPropagagation()}>
```
Works, but requires event on every interactive child. `closest()` is cleaner.
