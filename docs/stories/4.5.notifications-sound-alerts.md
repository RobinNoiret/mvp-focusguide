# Story 4.5: Notifications & Sound Alerts

**Epic:** 4 - Pomodoro Timer (Focused Execution Tool)
**Story Number:** 4.5
**Status:** Draft

---

## Story

**As a** user,
**I want** to receive notifications and hear alerts when timer completes,
**so that** I know when to break or resume focus.

---

## Acceptance Criteria

1. Request notification permission on first start
2. At 00:00, browser notification: "Pomodoro Complete!" with message
3. Notification includes Focus Guide icon
4. Click notification brings tab to focus
5. Sound alert plays: pleasant tone
6. Sound file: /public/sounds/pomodoro-complete.mp3
7. Audio API: new Audio().play()
8. If permission denied, toast: "Enable notifications..."
9. Settings modal: "Sound enabled" toggle
10. Notification works in background (PWA)
11. Notification bell icon has badge when complete
12. Integration test mocks Notification API

- [ ] Create `apps/web/hooks/useNotificationPermission.ts`:

  ```typescript
  import { useEffect, useState } from 'react'
  import { toast } from '@/hooks/use-toast'

  export function useNotificationPermission() {
    const [permission, setPermission] = useState<NotificationPermission>('default')

    useEffect(() => {
      if (!('Notification' in window)) {
        console.warn('Notifications not supported')
        return
      }

      setPermission(Notification.permission)

      // AC 1: Request permission on first start
      if (Notification.permission === 'default') {
        Notification.requestPermission().then((result) => {
          setPermission(result)

          // AC 8: Show toast if denied
          if (result === 'denied') {
            toast({
              title: 'Notifications désactivées',
              description: 'Activez les notifications dans les paramètres du navigateur pour recevoir des alertes.',
              variant: 'destructive',
            })
          }
        })
      }
    }, [])

    return permission
  }
  ```

### Task 2: Create Notification Service (AC: 2, 3, 4, 10)

- [ ] Create `apps/web/services/notificationService.ts`:
  ```typescript
  export class NotificationService {
    // AC 2, 3, 4: Show browser notification
    static async show(title: string, body: string, icon?: string) {
      if (!('Notification' in window)) {
        console.warn('Notifications not supported')
        return
      }

      if (Notification.permission !== 'granted') {
        console.warn('Notification permission not granted')
        return
      }

      // AC 2: Browser notification
      const notification = new Notification(title, {
        body,
        // AC 3: Focus Guide icon
        icon: icon || '/logo-192.png',
        badge: '/logo-96.png',
        // AC 10: Works in background (PWA)
        tag: 'pomodoro-complete',
        requireInteraction: false,
        silent: false, // Allow sound from browser
      })

      // AC 4: Click brings tab to focus
      notification.onclick = () => {
        window.focus()
        notification.close()
      }

      return notification
    }

    // Focus session complete
    static showFocusComplete() {
      return this.show(
        'Pomodoro Terminé!',
        'Temps de faire une pause. Excellent travail! 🎉',
        '/logo-192.png'
      )
    }

    // Break complete
    static showBreakComplete() {
      return this.show(
        'Pause Terminée!',
        'Prêt pour la prochaine session de focus? 💪',
        '/logo-192.png'
      )
    }
  }
  ```
- [ ] AC 2: Notification with title and body
- [ ] AC 3: Focus Guide icon
- [ ] AC 4: Click handler focuses window
- [ ] AC 10: PWA tag for background

### Task 3: Create Sound Service (AC: 5, 6, 7)

- [ ] Create `apps/web/services/soundService.ts`:

  ```typescript
  export class SoundService {
    private static audio: HTMLAudioElement | null = null

    // AC 7: Audio API
    static play(soundFile: string) {
      try {
        // AC 6, 7: Create Audio instance
        this.audio = new Audio(soundFile)
        this.audio.volume = 0.5 // 50% volume
        this.audio.play().catch((error) => {
          console.error('Failed to play sound:', error)
        })
      } catch (error) {
        console.error('Audio not supported:', error)
      }
    }

    // AC 5, 6: Play completion sound
    static playPomodoroComplete() {
      this.play('/sounds/pomodoro-complete.mp3')
    }

    static stop() {
      if (this.audio) {
        this.audio.pause()
        this.audio.currentTime = 0
      }
    }
  }
  ```

### Task 8: Add Notification Bell Badge (AC: 11)

- [ ] Create `apps/web/components/layout/NotificationBell.tsx`:
  ```typescript
  'use client'

  import { useState, useEffect } from 'react'
  import { Bell } from 'lucide-react'
  import { usePomodoroStore } from '@/stores/pomodoroStore'

  export function NotificationBell() {
    const { timeRemaining, isRunning } = usePomodoroStore()
    const [hasNotification, setHasNotification] = useState(false)

    // AC 11: Badge when timer completes
    useEffect(() => {
      if (timeRemaining === 0 && !isRunning) {
        setHasNotification(true)

        // Auto-clear after 10 seconds
        const timeout = setTimeout(() => {
          setHasNotification(false)
        }, 10000)

        return () => clearTimeout(timeout)
      }
    }, [timeRemaining, isRunning])

    const handleClick = () => {
      setHasNotification(false)
      // Navigate to Pomodoro page or show notification list
    }

    return (
      <button
        onClick={handleClick}
        className="relative rounded-full bg-[#D9FC00] p-3"
        aria-label="Notifications"
      >
        <Bell className="h-5 w-5 text-[#262626]" />

        {/* AC 11: Badge when notification */}
        {hasNotification && (
          <span className="absolute top-0 right-0 h-3 w-3 rounded-full bg-red-500 border-2 border-white" />
        )}
      </button>
    )
  }
  ```

## Dev Notes

### Notification Permission Flow (AC: 1)

**Browser API:**
```typescript
Notification.requestPermission()
```

**Returns:**
- "granted" → Can show notifications
- "denied" → Cannot show
- "default" → Not asked yet

**Best practice:**
Request on first timer start, not immediately.

**But for Pomodoro:**
Request on page load (user already intends to use timer).

### Notification API (AC: 2, 3, 4)

**Create notification:**
```typescript
new Notification('Title', {
  body: 'Message',
  icon: '/logo-192.png',
  badge: '/logo-96.png',
})
```

**Click handler:**
```typescript
notification.onclick = () => {
  window.focus() // Bring tab to front
  notification.close()
}
```

**PWA behavior (AC: 10):**
Notifications work even if browser tab in background.

### Sound File Selection (AC: 5, 6)

**Pleasant tone:**
- Soft, not harsh
- 1-2 seconds duration
- Medium volume

**Suggestions:**
- https://freesound.org/ (Creative Commons)
- https://mixkit.co/free-sound-effects/
- Create custom with Audacity

**Format:**
MP3 (widely supported, small file size).

### Audio API (AC: 7)

**Simple playback:**
```typescript
const audio = new Audio('/sounds/file.mp3')
audio.play()
```

**Auto-play restrictions:**
Modern browsers block auto-play without user interaction.

**Pomodoro exception:**
User already interacted (started timer).

**Volume:**
```typescript
audio.volume = 0.5 // 50%
```

Not too loud (respect user's environment).

### Sound Toggle (AC: 9)

**Why needed?**
- User in office (no sound)
- User wears headphones (prefers visual)
- Accessibility (deaf users)

**Default:**
Enabled (most users want sound).

### Notification Messages (AC: 2)

**Focus complete:**
"Pomodoro Terminé! Temps de faire une pause. Excellent travail! 🎉"

**Break complete:**
"Pause Terminée! Prêt pour la prochaine session de focus? 💪"

**Positive, encouraging:**
Motivates user.

### Notification Badge (AC: 11)

**Bell icon with red dot:**
Standard notification pattern.

**Auto-clear:**
After 10 seconds or user clicks.

**Why?**
User may not see notification immediately.

### Permission Denied Handling (AC: 8)

**Toast message:**
"Activez les notifications dans les paramètres du navigateur pour recevoir des alertes."

**Helpful:**
Explains how to fix.

**No blocking:**
Timer still works without notifications.

### PWA Notifications (AC: 10)

**Service Worker:**
Required for background notifications in PWA.

**Setup:**
```typescript
// In service worker
self.addEventListener('notificationclick', (event) => {
  event.notification.close()
  clients.openWindow('/')
})
```

**For MVP:**
Browser native notifications (no Service Worker yet).

**Future enhancement:**
Full PWA push notifications.

### Testing Notifications (AC: 12)

**Challenge:**
Browser Notification API not in Node.js.

**Solution:**
Mock global.Notification.

**Playwright:**
Can test in real browser with permissions.

### Accessibility

**Visual alternatives:**
- Notification badge
- Page title flash
- Visual animation

**For deaf users:**
Visual cues essential.

### Edge Case: Multiple Tabs

**Scenario:**
User has 2 Pomodoro tabs open.

**Problem:**
2 notifications + 2 sounds (annoying).

**Solution (future):**
Use BroadcastChannel to sync tabs, only one notifies.

**For MVP:**
Accept limitation.

### Browser Support

**Notification API:**
Supported in all modern browsers.

**Audio API:**
Widely supported.

**Fallback:**
Gracefully degrade (no notification, no sound).
