### Project Structure Overview

[Source: docs/architecture.md#Repository Structure]

Focus Guide uses a **monorepo structure with pnpm workspaces** to enable code sharing between frontend and backend while maintaining separation of concerns.

**Directory Structure:**
```
focus-guide/
├── apps/
│   ├── web/          # Next.js 14 frontend (App Router)
│   └── api/          # AdonisJS 6 backend (REST API)
├── packages/
│   ├── shared/       # Shared TypeScript types, constants, utils
│   └── config/       # Shared ESLint, TypeScript configs
├── docs/             # Project documentation
├── .bmad-core/       # BMAD framework (already present)
├── pnpm-workspace.yaml
├── package.json      # Root workspace config
└── README.md
```

**Rationale for monorepo:**
- Share TypeScript types between frontend and backend (critical for API contracts)
- Unified dependency management
- Simpler for 2-person team than separate repos
- Single CI/CD pipeline

### TypeScript Configuration Requirements

[Source: docs/architecture.md#Code Quality + Security Architecture]

**ALL packages MUST use TypeScript 5.3+ in strict mode.** This is non-negotiable for type safety across the monorepo.

**Required TypeScript compiler options:**
- `"strict": true` (enables all strict type-checking options)
- `"target": "ES2022"` (modern JavaScript features)
- `"module": "ESNext"` (ES modules)
- `"moduleResolution": "bundler"` (for Next.js compatibility)
- `"esModuleInterop": true` (CommonJS interop)
- `"skipLibCheck": true` (faster compilation)
- `"resolveJsonModule": true` (import JSON files)

**Shared base configuration:**
Create `packages/config/tsconfig.base.json` with these settings, then extend it in each package's `tsconfig.json`.

### pnpm Workspace Scripts

[Source: docs/architecture.md#Development Workflow]

**Root package.json workspace scripts MUST include:**

```json
{
  "scripts": {
    "dev": "pnpm --parallel --filter './apps/*' dev",
    "dev:web": "pnpm --filter @focus-guide/web dev",
    "dev:api": "pnpm --filter @focus-guide/api dev",
    "build": "pnpm --filter './apps/*' build",
    "test": "pnpm --recursive test",
    "lint": "pnpm --recursive lint",
    "format": "prettier --write \"**/*.{ts,tsx,js,jsx,json,md}\""
  }
}
```

**Usage:**
- `pnpm dev` starts both Next.js (port 3000) and AdonisJS (port 3333) in parallel
- Individual services can be started with `pnpm dev:web` or `pnpm dev:api`
- `pnpm test` runs tests in all packages recursively
